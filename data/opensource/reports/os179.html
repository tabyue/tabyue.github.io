为什么需要它

人形机器人运控研究有一个结构性矛盾：人形是强耦合、高维、接触频繁的系统，要学到稳定的全身运动需要海量交互样本，而真机采样的成本与风险都很高。因此研究几乎全部在仿真中进行，再迁移到真机。

问题是，做仿真训练要自己搭的东西太多：物理引擎接入、并行环境封装、观测与奖励设计、参考运动处理、训练循环与评测。ProtoMotions 把这些打包成一套可配置的栈，让研究者把精力放在「要学什么运动」而不是「怎么把仿真跑起来」。

它的独特视角：数字人与机器人同源

ProtoMotions 同时服务两类仿真体：

仿真体 典型任务 共同点
数字人（digital human） 角色动画、自然运动生成 高维关节、接触、平衡
真人形机器人 全身运控、运动模仿 同样的动力学结构

二者在数学上是同一个问题：一个带接触约束的高维刚体系统，如何产生自然且物理一致的运动。把它们放进同一套栈里，意味着角色动画领域积累的运动数据与方法可以直接服务于机器人。这一点在当下尤其重要——互联网视频与动捕数据的规模远大于机器人真机数据。

为什么奖励里要有「接触一致性」

只跟踪关节角会得到看起来对但物理上不对的运动——脚在地上滑、身体浮空。这与 PHUMA 数据集所指出的物理伪影是同一个问题：参考运动本身若物理不可靠，跟踪得越准反而越糟。因此奖励里必须显式加入接触与接地约束项。

并行规模的设计取向

GPU 并行是这类框架的核心。人形 RL 通常需要千万到亿级的交互步数才能收敛，单进程仿真根本无法在可接受时间内完成。ProtoMotions 的设计假设就是「上千个环境同时滚」，这也决定了它的观测与奖励必须是向量化、无 Python 分支的实现。

  • PHUMA: Physically Reliable Humanoid Locomotion Dataset — CoRL 2026 Spotlight，解决参考运动的物理伪影问题，是 ProtoMotions 的上游数据方案。
  • Whole-Body Dexterity — 全身接触操作的最新进展，把躯干与附肢当作接触面，可视为全身运动能力的下游拓展。

跑通一个运动模仿任务的典型顺序

  1. 准备参考运动：从动捕库（AMASS 类）或自有数据出发，先做物理可靠性筛选再重定目标；
  2. 配置仿真体：选择数字人或目标人形（如 Unitree G1 类），确认关节限位与状态维度；
  3. 定义奖励：位姿跟踪 + 根部速度 + 接触一致性 + 平滑正则；
  4. 启动并行训练：设置环境数量与批量大小，先小规模验证收敛趋势再放大；
  5. 评测与迁移：先看仿真内的跟踪误差与掉落率，再考虑真机。

奖励骨架示意

"""
运动模仿的奖励骨架：跟踪 + 接地/接触 + 正则。
"""
def imitation_reward(state, ref, cfg):
    r_pose = -((state.q - ref.q) ** 2 * cfg.w_joint).sum()      # 关节角跟踪
    r_root = -((state.root_vel - ref.root_vel) ** 2).sum()       # 根部速度
    r_contact = 0.0
    for foot, flag in zip(state.feet, ref.contact_flags):
        # 接触一致性：该接触时贴地、该腾空时离地
        r_contact += flag * state.height(foot) ** 2 \
                   + (1 - flag) * max(0, cfg.clear - state.height(foot)) ** 2
    r_smooth = -(state.qd ** 2).sum()                            # 抑制抖动
    r_limit = -cfg.w_limit * state.joint_limit_violation()       # 关节限位
    return (cfg.a * r_pose + cfg.b * r_root
            + cfg.c * r_contact + cfg.d * r_smooth + r_limit)

它解决的成本问题

一个中等规模的人形运控实验，若从零自建仿真—学习栈，工程量通常在数人周量级：环境封装、向量化观测、参考运动对齐、分布式训练、评测脚本。使用现成框架把这个成本压到配置级，研究迭代速度提升一个数量级。

与 PHUMA 的配套关系

ProtoMotions 负责把运动训出来，而训练质量高度依赖参考运动的物理可靠性。这正是 PHUMA 数据集（CoRL 2026 Spotlight）要解决的问题——它用物理感知筛选 + 物理约束重定向产出 73 小时物理可靠的人形运动数据，并已验证可零样本迁移到真实 Unitree G1。两者是上下游关系：先有可靠的参考运动，再谈高质量的运动模仿。
