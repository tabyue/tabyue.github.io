world-model-eval/world-model-eval 是论文「Evaluating Robot Policies in a World Model」的官方配套代码，研究一个越来越现实的问题：能不能用学到的世界模型代替真机或物理仿真器，给机器人策略打分与排序。

仓库 Python / MIT，2025-06-09 创建、2026-10-22 推送，约 117 star，项目页 world-model-eval.github.io/abstract。

为什么值得关注：世界模型当评测器比当训练环境更贴近近期落地节奏——策略筛选不必逐条上真机，但必须回答「模型里的分数与真机成功率是否同序」。这与本站 n645（Cosmos 3 开放权重）、n646（PrimeSim 开放训练代码）处在同一条链上，也与 p331 里「策略排序与物理仿真器一致」的验收口径呼应。

  1. 世界模型接口：把候选世界模型包装成统一的「给定状态与动作、预测后续观测」接口；
  2. 策略接口：把候选机器人策略包装成统一的「给定观测、产出动作」接口；
  3. Rollout 执行器：在世界模型里跑策略，记录预测轨迹与终止条件；
  4. 打分与排序：按任务成功判据给每条 rollout 打分，产出策略排序；
  5. 一致性检验：把世界模型内的排序与物理仿真器 / 真机排序做相关性对照。

分层要点：评测器与被测策略解耦，因此同一套流程可用于比较不同世界模型，也可用于比较不同策略。

  • Evaluating Robot Policies in a World Model（本仓库对应论文）：把世界模型定位为策略评测器；
  • 本站 p322 / p324 / p325：世界模型用于导航偏好蒸馏、紧凑策略与 3D 粒子推演；
  • 本站 n645（Cosmos 3 Nano） 与 n646（PrimeSim）：可直接下载权重、按动作生成后续视频，是评测器的现成候选；
  • 本站 p331（Latent RL Priors）：报告了世界模型内策略成功率与物理仿真器的相关系数，是「排序一致性」的实操参照。
  1. 克隆仓库，按 README 安装依赖并下载示例世界模型权重；
  2. 先跑官方示例，确认 rollout 能正常生成并产出策略分数；
  3. 用已知成功率的一组策略做校准，检查世界模型内排序是否与物理仿真器同序；
  4. 只有校准通过后，才把世界模型当作筛选工具使用；
  5. 保留一小部分真机 / 物理仿真复核，不要把世界模型分数写成最终验收结论。

该仓库的验收指标不是某个成功率数字，而是排序一致性：世界模型给出的策略名次与真机 / 物理仿真器名次的相关程度。使用时应报告相关系数与置信区间，而不是只报「筛出了更好的策略」。
