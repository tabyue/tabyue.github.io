emoPointer/supermimic_manipulation 是 SuperMimic 的官方实现：在 mjlab 中面向状态基（state-based）机器人操作，做世界模型引导的策略优化。

仓库 Python / MIT，2026-10-25 创建、2026-10-31 推送，约 72 star。

为什么值得关注：多数世界模型工作把精力放在像素级视频预测上，而状态基设定把问题收回到「学到可用的动力学、再拿它改策略」这条更干净的链路，便于隔离表征误差与策略误差。配合本站 world-models-llm、reinforcement-learning 相关章节，可作为从「预测下一状态」走到「用预测改进动作」的最小可跑参照。

  1. 任务环境：基于 mjlab 的状态基操作任务，观测是低维状态而非图像；
  2. 世界模型 / 动力学模型：学习状态转移，预测动作后的后续状态；
  3. 策略优化：用学到的模型做 rollout 或提供梯度信号，改进操作策略；
  4. 真值校验：把模型预测与真实环境推进做对照，隔离模型误差；
  5. 闭环迭代：模型与策略交替更新，避免模型在策略分布外失准。

要点是低维状态把表征问题暂时移出画面：如果在这条链路上策略仍改不动，问题更可能在优化或模型利用方式，而不是视觉编码。

  • SuperMimic（本仓库对应方法）：世界模型引导的状态基策略优化；

  • 本站 world-models-llm / reinforcement-learning 模块：世界模型与基于模型 RL 的教材级背景。
  1. 按 README 安装 mjlab 与 Python 依赖；
  2. 跑通一个状态基操作任务的环境推进，确认状态与动作维度；
  3. 训练动力学模型，先在固定策略下核对一步 / 多步预测误差；
  4. 开启策略优化，观察模型预测误差与策略收益是否同步改善；
  5. 若收益停滞，先排查模型在策略访问区域内的误差，而不是急着调 RL 超参。

评价这条路线应看三个量：模型的多步预测误差、策略优化前后的成功率差、以及模型误差与策略收益的相关性。状态基设定下这些量更容易归因，是它相对像素级世界模型的主要优势。
