NVlabs/alpamayo2-edge 是 NVIDIA 官方放出的 2B 参数端侧推理型 VLA：以自适应推理生成轨迹，并给出因果层面的解释。仓库 2026-10-06 创建、2026-11-10 仍在推送，Python 实现，采用 Apache-2.0 明确授权（本轮 4 个新收录项目里授权最清晰的一个）。

为什么值得关注：具身智能正在同时被两端拉扯——一端是 14k 小时预训练的通用世界动作模型（p348 LaST0.5），另一端是必须塞进机器人本体、受功耗与实时性约束的端侧芯片（n679 曦选创智对标 Thor 的「大小脑一体」SoC）。Alpamayo 2 Edge 正处在后一端：2B 的体量、按难度调节推理深度的自适应推理，都是把模型放进有限算力预算的具体手段。它和同门的 NVlabs/alpamayo-recipes（os239，微调 / RL 后训练 / 量化 / 部署的开发者中心）配套读，能看到 NVIDIA 从训练到端侧部署的完整一条线。

按「端侧推理型 VLA」的定位，仓库的组织应围绕三件事（具体目录以 README 为准）：

  1. 轻量骨干与动作/轨迹头：2B 参数规模决定了它不能照搬 7B 以上通用 VLA 的结构，输入侧多模态编码与输出侧轨迹表示都需要压缩；轨迹而非单步关节指令，是它区别于操作类 VLA 的一个信号。
  2. 自适应推理模块：按输入难度决定推理深度或调用次数，把算力花在难样本上。这与本轮 p349（Elastic-WAM 用时空精化需求场自适应分配去噪算力）、p351（BEHAVIOR 方案用噪声—算力模型挑选流匹配样本数）是同一类工程思想在不同层的落地。
  3. 因果解释输出：除轨迹外给出因果层面的说明，便于调试与审计——在车载与机器人这类安全敏感场景，可解释性不是装饰而是验收项。
