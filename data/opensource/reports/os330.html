huggingface/lerobot-dataset-visualizer 是 Hugging Face 官方的 LeRobot 数据集可视化 Web 应用，Apache-2.0、TypeScript，2025-09-03 创建、2026-11-16 更新，约 139 star。定位是在训练之前先把数据看明白：交互式浏览大规模机器人数据集，把同步视频播放与丰富的时序数据图表放在一起，让研究者快速判断一个 episode 是否可用。

它面向 LeRobot 格式（README 标注 v2.0+ 最新数据集格式），从远端拉取数据集元数据与 episode 数据（含视频与传感器／遥测），提供组织—数据集—episode 三级导航、同步视频与交互图表、数据集统计（episode 数、总录制时长、帧率、时长直方图）、动作质量分析（自相关、状态—动作对齐、速度分布、跨 episode 方差热力图）、问题 episode 筛选（低运动、抖动、时长离群）并可直接导出成 LeRobot CLI 命令，以及基于 USD 模型的 3D 逐帧重放（末端轨迹渲染）与 SOMA156 手部标注的 21 关节骨架显示。

star 不高但维护方是 LeRobot 生态本身，是本轮四篇数据相关论文与资源导航里最实用的一件工具。

按 README 的功能列表可归纳为四层（结构性归纳，具体以仓库文档为准）：

  1. 数据接入层：通过 HF OAuth（read-repos）拉取数据集元数据、episode 视频与传感器／遥测数据，并按组织—数据集—episode 三级做分页，避免一次性下载整个大规模数据集。
  2. 同步展示层：视频播放与交互时序图表共享同一时间轴，因此能定位「哪一帧的动作或状态出现异常」；Overview 面板给出相机信息、episode 元数据，Statistics 面板给出帧率与时长分布。
  3. 质量诊断层：Action Insights 用自相关、状态—动作对齐、速度分布、跨 episode 方差热力图指示训练配置问题；Filtering 面板把低运动、抖动、时长离群的 episode 标记出来，并导出可直接运行的 LeRobot CLI 删除／筛选命令。
  4. 三维与手部重放层：用 USD 模型逐帧显示关节位姿与末端轨迹，支持 SO-100、SO-101、OpenArm 双臂、Unitree G1（Dex3／Dex1／Inspire／BrainCo 手）；自动检测原生 SOMA156 手部标注，显示腕部、21 关节骨架与相机轨迹叠加。

部署形态是 Hugging Face Space（sdk: docker、app_port 7860），也可本地起容器。这四层与本轮深化的 /learn/sim-to-real 第 4 节（几何重建与物理参数辨识）以及 /learn/ai-infra 数据集格式标准章节形成上下游：格式标准决定数据能不能被复用，可视化器决定复用前能不能发现脏数据。

最小上手路径

  1. 直接使用 Hugging Face 上的 LeRobot Dataset Visualizer Space（需 HF 账号授权 read-repos），选组织与数据集即可浏览；本地部署则按仓库 Dockerfile 起容器，默认端口 7860。
  2. 打开一个 LeRobot v2.0+ 数据集，先看 Overview 与 Statistics：episode 数、总时长、帧率、时长直方图，确认时间戳口径与相机数量。
  3. 随机抽 5—10 个 episode 做同步播放，观察视频画面与状态／动作曲线是否对齐——若动作曲线相对画面提前或滞后，优先排查采集端的时间对齐而非模型。
  4. 用 Action Insights 看自相关与状态—动作对齐，判断动作分块长度与训练时的观测窗口该怎么设。
  5. 用 Filtering 面板标记低运动、抖动、时长离群的 episode，导出 LeRobot CLI 命令，在训练前生成清洗后的数据版本并留存版本号。
  6. 对有 USD 模型的本体（SO-100／SO-101／OpenArm／Unitree G1）开 3D Replay，逐帧核对末端轨迹；有 SOMA156 标注时打开 3D Hands 看腕部轨迹与相机叠加。
  7. 把「清洗前后」的数据各训一次同样的策略做对照，用成功率差值量化数据体检的收益。
