Sirui-Xu/InterMimic 做的是物理仿真下的人形全身动作跟踪，目标不是复现单人舞蹈，而是让同一套控制器跟随含人与物体交互的参考运动（搬箱、推拉、坐下、接触支撑等），并把技能迁移到真机（CVPR 2025 Highlight，MIT，约 559 star）。

它把「参考运动里有人—物接触」这一常见却难处理的情形显式建模：无接触的动作跟踪可以靠纯运动学匹配加平衡奖励糊过去，一旦人要靠在桌子上有支撑力、或双手抬着一个箱子，缺少接触力的跟踪策略会因为动力学不一致而崩溃——仿真里看着跟上了，真机上直接摔。

import numpy as np

def tracking_reward(ref, sim, contact_ref, contact_sim, w=(1.0, 0.5, 0.3, 0.2)):
    '''Decompose the reward so contact failure is visible.

    ref / sim: dict of joint angles, root pose, end-effector positions
    contact_ref / contact_sim: binary contact flags per end effector
    '''
    pose = -np.mean((np.array(ref['q']) - np.array(sim['q'])) ** 2)
    eef = -np.mean(np.linalg.norm(
        np.array(ref['eef']) - np.array(sim['eef']), axis=-1) ** 2)
    contact = -np.mean(np.abs(
        np.array(contact_ref) - np.array(contact_sim)))
    smooth = -np.mean(np.diff(np.array(sim['q']), axis=0) ** 2)
    return float(w[0] * pose + w[1] * eef + w[2] * contact + w[3] * smooth), {
        'pose': pose, 'eef': eef, 'contact': contact, 'smooth': smooth}

对含接触的全身动作跟踪，该核对的是四项：

  1. 接触建立 / 断开瞬间的误差：平均跟踪误差低不代表接触时序对，分段统计才有意义；
  2. 消融后的失败模式：关掉接触项后是摔倒还是姿态偏移，决定了接触建模是否真的在起作用；
  3. 域随机化的敏感参数：真机迁移对哪类参数最脆弱，决定部署前要标定什么；
  4. 未见物体的泛化：学到的是接触结构还是特定物体动力学，决定它能不能叫「通用」全身控制。
