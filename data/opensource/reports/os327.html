它与本轮 p418 Latent Jacobian Steer 构成同一问题族的两种解法。LJS 冻结预训练控制器，在测试时用策略雅可比把动作扰动映射成潜命令、靠搜索组合出 OOD 行为；vibe 则走训练期后训练路线，用 PPO 继续改造跟踪器。两者对照，正好把「冻结基础模型 + 测试时搜索」与「后训练适配」的分工讲清楚。

按仓库描述与 topics 可归纳为四块（结构性归纳，具体以 README 与项目页为准）：

  1. 预训练跟踪器底座：以已有的人形全身运动跟踪器为起点（跟踪参考动作/速度指令），不从头训。
  2. 后训练阶段：在底座上用 PPO 继续训练，把任务目标从「跟得像」扩展到「在带感知的任务里做成」。
  3. 感知输入接入：把地形/视觉/深度观测接进策略，形成 perceptive locomotion 的闭环，同时要处理感知噪声与时延。
  4. mjlab 训练与评估：仿真训练、域随机化与策略评估沿用 mjlab 栈。

为什么是「后训练」而非「重训」：全身跟踪器已经学到了协调的步态与平衡先验，从零训感知控制会丢掉这些先验、样本效率极差。后训练保留先验、只增量适配，这与 p418 里「潜空间探索保留协调性」的动机其实是同一个判断。

常见坑

  • 没有先拿到可用的预训练跟踪器权重就想跑后训练，仓库通常不自带底座。

  • 只报成功率不报跟踪误差，看不出后训练是否损害了原有步态质量。
