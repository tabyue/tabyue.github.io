VAGEN：面向多轮 VLM 智能体的世界模型强化学习框架，把「想象未来」接进视觉 Agent 的训练回路（NeurIPS 2025）

多轮视觉 Agent 的 RL 训练之难，在于「看—想—做—再看」这条回路每一步都很贵：真实交互慢、视觉观测高维、奖励往往只在最后给一次。VAGEN 的切入点是把世界模型放进这条回路：Agent 不必每一步都真实执行，可以在潜空间里预测未来若干步的结果，用这些预测来稠化奖励信号、降低对真实交互样本的依赖。这让「视觉 Agent 的 RL 训练」从不可行变得可行。

框架分层为：环境接口层（统一多轮交互的观测/动作协议）、世界模型层（在潜空间做短期 rollout，预测未来观测或状态表征）、策略层（VLM 驱动的 Agent 策略，按轮次产出动作或文本决策）、RL 训练层（用世界模型辅助的信号做策略优化）。关键在于世界模型与策略的解耦——世界模型负责「世界怎么变」，策略负责「我该做什么」，两者可以分别预训练与更新。

  • LeWAM — 用 JEPA 做端到端世界与动作建模，与 VAGEN 的解耦路线对照。
  • RLinf — 具身与 Agentic AI 的 RL 基础设施，可与 VAGEN 组合使用。
  • Toward Recursive Self-Improvement in Physical AI — 物理 AI 自改进的路线综述，理解世界模型 + RL 的定位。

上手路线：先在一个简单的视觉任务（如带视觉观测的网格世界或多步 GUI 任务）上跑通基线多轮 Agent，记录样本效率与最终成功率；再接入世界模型模块，对比「有/无潜空间 rollout」两种设置下的学习曲线；关键是分别固定世界模型与策略的更新频率，观察谁先成为瓶颈。注意世界模型的预测 horizon 是核心超参——太短起不到稠化奖励的作用，太长会累积误差反而误导策略。

评估应报四条：最终任务成功率、达到给定成功率所需的真实交互样本数（这才是样本效率的证明）、世界模型自身的预测误差随 horizon 的退化曲线、以及策略更新与世界模型更新的算力分配。只报最终成功率无法区分「世界模型真的有用」与「只是多训了一会儿」。

与 RLinf 相比：RLinf 面向具身与 Agentic AI 的大规模分布式 RL 基础设施，解决「训得动、训得快」；VAGEN 专注「视觉多轮决策怎么训得有效」，是算法范式层面的框架。与 LeWAM 相比：LeWAM 用 JEPA 做端到端世界与动作建模，把预测与动作放进同一套权重；VAGEN 保持世界模型与策略解耦，更灵活但需要分别维护。与纯 SFT 路线相比：RL 路线能优化多轮交互中的序贯决策质量，代价是训练复杂度与算力显著上升。
