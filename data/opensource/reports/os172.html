为什么「更多专家示教」这条路已经到顶

专家示教只告诉模型「正确的路怎么走」，几乎不包含「手多伸出去两厘米会怎样」。而机器人真正需要的因果知识恰恰在后者里——只有见过后果，才知道边界在哪。

从部署数据里学则面临两难：

用法 问题
模仿所有记录的动作 强化次优甚至失败行为
只保留成功样本 丢掉物理交互及其后果的证据

LoopWAM 的核心洞察是：失败样本的动作不该学，但它记录的「世界怎么变」依然该学。

解法：把行为学习与世界建模拆开加权

  • 世界建模（视频预测）：所有质量层级的样本都保留完整监督——失败样本同样展示了真实的物理后果
  • 行为学习（动作模仿）：按样本质量加权——好的多学、坏的不学

这就同时拿到了「见过后果」与「不学坏动作」。

并行去噪让两者真正交互

视频 token 与动作 token 在整个去噪过程中持续交互，而不是各自算完再拼接。这意味着动作生成时能看到「如果我这么做，画面会变成什么样」——学到的后果直接参与决策。

双路径并行去噪

$$\text{Policy 路径}: \quad p(a_{t:t+H} \mid o_t, \ell)$$

$$\text{FDM 路径}: \quad p(o_{t+1:t+H} \mid a_{t:t+H}, s_{t+H}) \quad \text{（前向动力学）}$$

$$\text{IDM 路径}: \quad p(a_{t:t+H} \mid o_t, o_{t+H}) \quad \text{（逆动力学）}$$

三条路径在并行去噪中交互，而非串行。

来源相关噪声采样

不同来源的样本（自身策略 vs 其他已部署策略）施加不同的噪声调度：

$$\epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2_{\text{source}(i)}), \qquad \sigma_{\text{self}} \neq \sigma_{\text{other}}$$

这一个机制同时服务两个目标：对自身数据偏向行为学习，对其他来源数据偏向世界建模。

质量加权监督

$$\mathcal{L} = \underbrace{\mathcal{L}{\text{video}}}{\text{全质量保留}} + \lambda(q) \cdot \underbrace{\mathcal{L}{\text{action}}}{\text{按质量加权}}$$

其中 $q \in [0,1]$ 是样本质量分，$\lambda(q)$ 单调递增。失败样本 $q \to 0$ 时 $\lambda \to 0$——动作不学，但视频监督保留。

"""
质量加权监督示意：视频监督全保留，动作模仿按质量打折。
"""
def loopwam_loss(batch, model):
    q = batch['quality']                     # 每样本质量分 in [0, 1]
    noise_scale = source_noise(batch['src'])  # 来源相关噪声

    video_pred = model.denoise_video(batch['obs'], batch['act'], noise_scale)
    action_pred = model.denoise_action(batch['obs'], batch['lang'], noise_scale)

    loss_video = mse(video_pred, batch['obs_next'])          # 不做质量折扣
    loss_action = (quality_weight(q) * mse(action_pred, batch['act'])).mean()

    return loss_video + loss_action

最小验证流程

  1. 先确认数据里同时有成功与失败样本：如果只有专家示教，LoopWAM 的机制无从发挥。先跑一轮部署采集，或者直接构造含失败的数据集
  2. 验证质量分 $q$ 的可靠性：$q$ 是整个方法的枢纽。先人工标注一小批样本，确认自动质量分与人工判断一致
  3. 做「失败样本保留 vs 删除」的对照：这是最关键的消融。保留失败样本但动作权重为 0，应该显著优于直接删掉
  4. 看视频预测质量：世界建模分支学得好不好，可以用「给定动作预测下一帧」的误差直接衡量，这个指标比最终成功率反馈快得多
  5. 再跑闭环迭代：三轮部署-训练，记录每轮成功率变化（论文：23.67% → 43.33%）

排错要点

  • 闭环迭代不涨反跌：质量分不准，把次优样本当成功学进去了。先修 $q$，别急着调模型
  • 视频预测误差降不下去：噪声调度对不同来源区分不够，检查 $\sigma_{\text{source}}$ 是否真的不同
  • 动作分支学到坏行为：$\lambda(q)$ 的下界不够低，失败样本的动作权重仍有残量
  • 训练不稳定：并行去噪的交互强度是可调项，交互过强会让两条路径互相干扰

怎么读 23.67% → 43.33%

这个提升来自三轮闭环，不是单次训练。它的意义在于证明「部署本身可以作为训练数据来源」——每部署一轮，产生的成功/次优/失败样本都能转化为下一轮的改进。这对工业落地尤其重要：产线上的机器人每天都在产生 rollout，如果能自发利用，改进就不再依赖额外标注。
