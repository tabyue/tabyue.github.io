EvolvingLMMs-Lab/NEO 是「原生视觉语言模型」系列主仓库，VLAKit 子目录承载本轮 p378（From Pixels to Actions -- Towards Native Vision-Language-Action Policies）的 VLA 实现。仓库 2025-10-16 建立、2026-11-11 仍有推送，Apache-2.0，约 928 star，主语言 Python。

它挑战的是 VLA 里几乎从不被质疑的默认接口：图像先经 CLIP / SigLIP / DINOv2 等预训练编码器压缩，动作推理只能从编码器固定的末端输出开始。NEO 把图像切成 patch 后用轻量卷积层投影成 token，与语言 token 一起进入共享主干共同演化，动作专家（flow matching）按指令条件从主干不同深度抽取视觉表征。整条视觉通路没有独立的预训练编码器。

  1. Patch 卷积 token 化：轻量卷积把图像切成 patch 并投影到与文本同维的 token 序列，保留局部几何与边缘信息，不做语义压缩。
  2. 共享主干：视觉 token 与语言 token 拼接后在同一 Transformer 内逐层共同演化，跨模态注意力从第一层就发生。
  3. 跨层动作接口：flow-matching 动作专家通过跨层连接读取若干中间层的指令条件表征，而不是只读最后一层。
  4. 层探针工具：可在各层后挂轻量动作头，冻结主干单独训练，扫描「哪一层对动作最有用」。
  5. 训练与评测：支持常规操作设定与视角、背景、纹理等分布偏移评测；论文另在 Hugging Face 发布 NEO-VLA 权重与动作预训练数据。
  6. 仓库组织：VLAKit 只是 NEO 系列的一个子目录，主仓库还包含原生视觉语言模型的预训练与多模态理解部分。

这个结构把「用哪一层视觉特征」从经验调参变成可学习、也可测量的量。
