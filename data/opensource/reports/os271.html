AgibotTech/LIFE（Learning to Live: A Step Toward Lifelong Embodied Intelligence）是智元远征 Research Team 与清华 2026-11-11 发布的终身具身智能框架，Apache-2.0，代码、论文（arXiv 2611.00180）、项目主页与 RoboBeats 系列模型权重同步开放。仓库 2026-11-04 创建、11-10 仍在推送，Python。

它解决什么：今天的 VLM 智能体多按「推理—调工具—等结果」串行走，工具没返回世界已经变了；任务一结束状态清零，下次进同一间办公室仍像陌生人。LIFE 把调度单位从「一次任务」换成「一整天」——没人叫它时也在持续留意环境，把值得记的变化存下来，等新问题出现时再调用。

为什么收录：本站 embodied-agent 模块讲 Harness 层「把冻结模型组织成会自我改进的具身 Agent」，mobile-robot-navigation 讲长程导航记忆，p347 从评测侧证明「按时间均匀采帧」会造出幻影进度。LIFE 是这三者的工程合流：RoboBeats 管「持续看」，Plastic Memory 管「按什么写」，EDM 管「能力怎么长出来」。与 n683 是同一事件的代码侧，与 n694（成都贡嘎层次化场景图 + 时空记忆）构成两条可对照的技术路线。

框架由三块协同，外加一个 VLM Agent Core 调度：

  1. RoboBeats（心脏 / 轻量决策模型）：不生成文字，直接判断每个自然语言条件成立与否的概率，并复用视频流计算缓存。单张 RTX 5090 上 RoboBeats-2B 处理一帧新画面约 75 ms，同时盯 16 个条件约 77 ms——多留意几件事，延迟几乎不变。有任务时 Agent 用自然语言告诉它盯什么；没任务时它也在看，把「有人经过 / 物品换位 / 门开了」这类事件挑出来交给下游。
  2. Plastic Memory（可塑性记忆）：把当时的画面和当时的理解分开保存——原图留现场，JSON 记时间、位置、人物、物品等线索。扁平化设计让同一份记忆有两种用法：执行智能体通过工具快速检索文本线索；会读文件、写程序的编程智能体可回看原图，补上门牌、物品颜色等当初没写进文字的细节。
  3. EDM（Explore–Distill–Mount，能力复用）：沿用前作 ReSight 的机制。遇到「这样的电话亭我以前见过几个」这类现有工具答不了的问题，编程智能体查看历史证据、写程序摸索检索与去重办法；有效办法经提炼、验证后装进工具箱，下次不用从头再来。记忆里的画面没变，机器人却多了一种使用它们的方式。
  4. Agent Core：把眼前看到的、过去记住的与用户需求放一起，判断下一步做什么，再编排工具（证据检索、移动探索、操作物体、安装新技能）。
