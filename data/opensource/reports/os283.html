runwayml/praxis-1-oss 是 Runway 在 2026 年 11 月 11 日以 Apache 2.0 放出的世界动作模型（World Action Model）Praxis-1 官方仓库。它不是只放权重：推理代码、全量微调与 LoRA 微调代码一并开放，明确允许商用。模型定位是「一个系统同时预测场景接下来长什么样、机器人接下来该怎么动」——与纯 VLA 直接把观测映射成动作不同，Praxis-1 把未来视频块与动作块放在同一次去噪过程里联合生成。

发布规格：27.2B 参数 MoE 视频扩散主干（20 层 Dual-stream Diffusion Transformer 里 17 层用 MoE，1 共享专家 + 128 路由专家、每 token 激活 8，DeepSeek-V3 式无辅助损失负载均衡；冻结 Wan2.2 VAE 与 Qwen3.5-2B 编码器），配 314M 参数 16 层动作专家（宽度 1024，自注意力与交叉注意力交替，8 个 encoder block）。base checkpoint 为 BF16 54.4 GB，分 17 个 safetensors 分片，另有 NVFP4 量化变体。

分发渠道覆盖 GitHub、Hugging Face（原生 LeRobot 支持）、vLLM-Omni 与 Runway Reactor 托管推理；官方称可在 H100 / B200 数据中心卡、RTX 5090 / RTX PRO 6000 工作站卡，直到机器人本体上的 Jetson Thor 运行。它也是 Runway 作为 Cosmos Coalition 创始成员、与 NVIDIA 一起推动开放世界模型的一部分。

  1. 输入层：语言指令（文本）、最近若干相机帧（外部视角 + 腕部视角，224×416 tiles）、当前本体 proprioceptive 状态。
  2. 编码层：冻结的 Wan2.2 VAE 把图像压成潜帧；Qwen3.5-2B 文本编码器处理指令；本体状态经轻量投影进入同一 token 空间。
  3. 主干：26.9B MoE 视频扩散 DDT（每 token 约 2.8B 激活参数，1 共享 + 128 路由专家、top-8），chunk-causal 结构保证一个控制块内的时序因果。
  4. 动作专家：314M 稠密网络，16 层，自注意力与对视频主干的交叉注意力交替，负责输出动作块。
  5. 联合输出：每次控制调用产出 6 个潜视频帧 + 24 步动作（15 Hz，合计 1.6 秒），视频与动作在共享的去噪时间轴上共同生成。
  6. 跨本体适配层：新本体只需 6 个轻量状态 / 动作投影张量；仓库提供 scripts/init_heads.py 为任意新机器人初始化这些头，无需重训主干。
  7. 量化与部署：BF16 与 NVFP4 两类 checkpoint，配 vLLM-Omni 推理路径与 Reactor 托管入口。

这个结构的要点是「视频与动作共享一条去噪轨迹」：动作专家不是读一段生成好的视频再规划，而是在同一潜空间里与视频块共同被去噪出来，因此视频预训练学到的物理直觉能直接约束动作输出。
