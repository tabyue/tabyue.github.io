LeRobot Humanoid 是什么

LeRobot Humanoid 是 Hugging Face 推出的 约 2500 美元的开源双足人形平台。

要理解它的意义，需要先理解它要解决的问题。过去「教机器人走路」这件事的结果高度依赖实验室条件：每家机构用的是自己改造的本体、自己调的结构参数、未公开的质量分布与减速器回差。结果是——论文 A 报告「我们的方法让机器人学会了走」，但你用论文 A 的方法在自己的机器人上复现，几乎必然失败，因为 你连机器人都不一样。

LeRobot Humanoid 的解法是把整条链路标准化：

lerobot-humanoid-design 控制导向的设计工作流
lerobot-humanoid-hardware 机械装配文档、制造文件、BOM、STL

关于发布范围

当前发布 聚焦双足平台，上半身硬件不在本次发布范围内。

这是一个务实的取舍：双足行走本身就是难度足够高的独立问题，把上半身加进来会让机械复杂度、控制复杂度和装配难度同时翻倍。先解决「走」，再解决「走的同时干活」。

2500 美元这个数字意味着什么

对比一下数量级：商业研究级人形平台通常在 5 万—100 万元区间。2500 美元把门槛压到了 个人开发者与小型实验室可以承受 的范围。

这带来的不只是一个便宜的机器人，而是 研究可复现性的基础设施：当多个团队用同一台硬件时，A 报告的分数 B 才能真正对照。这与 ImageNet 对视觉、LLaMA 生态对语言模型的作用是同构的。

「控制导向的设计工作流」值得单独说

lerobot-humanoid-design 这个仓库的存在，反映了一种与传统机械设计不同的思路。

传统流程是：设计结构 → 加工 → 装配 → 发现走不稳 → 改控制参数 → 还是不行 → 改结构。这个循环极慢，因为每次迭代都要动硬件。

控制导向的设计把顺序反过来：

  1. 用 简化机器人表示（如集中质量模型、简化腿长与质量分布）做设计空间探索
  2. 对每个候选设计，用 最优控制基准（如轨迹优化求解一个标准行走问题）评估其控制难度
  3. 只有在控制上可行的设计，才进入详细机械设计

关键洞察是：有些机械设计在控制上根本不可行，无论算法多好。比如腿太长而脚太小，支撑多边形面积不足；或者质量分布集中在躯干上部，导致倒立摆动力学过于激进。这些用最优控制基准在几分钟内就能筛掉，而用试错要几个月。

硬件子装配体组织

STL 按 左腿 / 右腿 / 躯干 组织，这个划分不是随意的：

  • 左右腿完全对称 → 只设计一次，镜像生产；也便于只换一侧做备件
  • 躯干独立 → 承载电池、主控、IMU，改动频率与腿部不同
  • 每个子装配可 独立加工与预装配，最后总装

这种划分对自制者特别友好：可以并行加工三个子装配，任何一个出问题不会阻塞全部。

为什么电子接线映射值得单独提供

这一项在多数开源硬件项目里是缺失的，但它恰恰是自制失败率最高的环节之一。

22—29 个自由度意味着几十根线缆，涉及电机动力、编码器信号、通信总线、传感器供电。接错一根的后果轻则某个关节不动，重则烧毁驱动器。提供标准化的连接器映射 + 接线表，等于把「电气工程师的经验」固化成文档。

配合 lerobot-humanoid-runtime 里的 电机扫描工具，可以在通电前先逐个验证电机编号与通信是否正常。

采购与准备

# 1. 从硬件仓库获取 BOM 与制造文件
git clone https://github.com/huggingface/lerobot-humanoid-hardware.git
cd lerobot-humanoid-hardware

按 BOM 清单采购。建议注意三点：

  1. 电机按 1.2 倍数量采购——装配损坏与个体差异是常态，不要刚好买够
  2. 连接器宁可买多不买少——这是最容易缺料的部分
  3. 确认加工能力——STL 需要 3D 打印或 CNC；若没有条件，先确认本地加工服务的精度能否达到图纸公差

加工与预装配

# 按子装配体导出打印文件（路径以仓库实际结构为准）
ls stl/left_leg/  stl/right_leg/  stl/torso/

装配顺序建议：

  1. 先做电机预组装调试——用仓库提供的工具逐个扫描电机，确认通信与编码器正常。这一步不要跳过，装好再拆的代价是数小时
  2. 装配单腿——先完成一条腿，验证关节活动范围与无干涉
  3. 镜像装配另一条腿
  4. 装配躯干——安装电池、主控、IMU
  5. 总装与接线——严格按接线映射表执行

通电前检查清单

  • [ ] 所有电机已通过扫描工具单独验证
  • [ ] 接线与连接器映射表 逐根核对（不是抽查）
  • [ ] 关节活动范围内无机械干涉（手动转动每个关节）
  • [ ] 电池极性与电压确认
  • [ ] IMU 刚性固定，未贴在会形变的位置
  • [ ] 急停开关可达且功能正常

最后一项尤其重要：双足机器人一旦跌倒，力矩可能远超额定值，没有可靠的急停会损坏电机甚至伤人。

成本分解的意义

2500 美元这个数字的价值不在于绝对值，而在于它让以下几件事变得可行：

  • 个人开发者可以拥有一台人形机器人
  • 一个实验室可以买 10 台 做多机实验，而不是买 1 台
  • 论文结果可以被真正复现（同一硬件 + 同一模型资产）

第三点是最深远的。过去人形机器人研究的大量结论无法复现，本质原因是硬件不一致。当硬件成为标准件后，这个领域才有可能像视觉、NLP 那样积累。

LeRobot Humanoid 的独特位置

它的核心优势不是硬件性能，而是 与 LeRobot 生态的原生打通。

LeRobot 提供了：统一 Robot 类接口、标准化数据集格式（Parquet + MP4）、SOTA 策略实现（ACT / Diffusion / π0 / π0.5 / GR00T N1.7 / SmolVLA 等）、LIBERO/MetaWorld 评测脚本。LeRobot Humanoid 作为其原生支持的本体之一，意味着你采集的数据、训练的策略可以 直接复用整个生态的工具链，不需要自己写数据转换。

这一点对研究者意义重大：过去大量时间花在「把我的机器人数据转成能训练的格式」上，现在这部分被标准化了。
