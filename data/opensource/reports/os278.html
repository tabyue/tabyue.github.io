  2. 想象轨迹评估：按任务目标给每条候选未来打分（是否达成、代价、风险），这一步决定预演有没有用；
  3. 上下文构造：把得分高的想象轨迹连同当前观测、任务描述组织成 in-context 示例，喂给冻结的策略 / Agent；
  4. 动作决策：Agent 依据上下文输出动作序列，不更新任何权重——行为改变来自上下文而非梯度；
  5. 执行与反馈：真机 / 仿真执行后把新观测写回，进入下一轮预演，失败轨迹也进上下文用于纠错；
  6. 预算参数：预演步数、候选条数、上下文长度、每轮 token 上限都是显式可调项，构成测试时扩展的调节旋钮。

import numpy as np

def world_in_context_step(world_model, agent, obs, task,
                          n_rollouts=4, horizon=8):
    '''One round of World In-Context Learning (schematic).'''
    candidates = []
    for k in range(n_rollouts):
        prefix = agent.propose_prefix(obs, task)
        imagined = world_model.rollout(obs, prefix, steps=horizon)
        score = task.score(imagined[-1])          # external criterion matters
        candidates.append((score, prefix, imagined))

    candidates.sort(key=lambda z: -z[0])
    top = candidates[:2]
    context = agent.build_context(obs, task, top)  # imagined futures as examples
    action_seq = agent.act(context)                # weights stay frozen
    return action_seq, [c[0] for c in candidates]

对「把推理预算花在预演上」这类方法，该核对的是四项：

  1. 预演 vs 纯提示的净增益：消融掉想象轨迹后成功率掉多少，这是路线成立与否的唯一硬判据；
  2. 预算曲线：成功率随候选条数 / 预演步数的饱和点在哪，超过之后就是在白烧 token；
  3. 世界模型偏差的传导：模型系统性偏乐观时，Agent 是否被带偏，评估环节是否需要外部判据；
  4. 失败轨迹的复用：写回上下文后同类错误是否真的减少，而不是每轮重新犯。
