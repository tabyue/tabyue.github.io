Robotic World Model (RWM) 来自 ETH Zürich 的 Robotic Systems Lab，仓库收录两篇配套工作：Robotic World Model: A Neural Network Simulator for Robust Policy Optimization in Robotics 与 Uncertainty-Aware Robotic World Model Makes Offline Model-Based Reinforcement Learning Work on Real Robots。

核心主张是把世界模型训练成可查询、可 rollout 的神经网络仿真器，让策略在里面做基于模型的强化学习，而不是只拿来生成「看起来像」的视频；第二篇进一步引入不确定性感知，使离线 MBRL 不至于在模型失真的区域被「想象出来的高回报」带偏，从而把策略迁到真机。仓库为 Python / Apache-2.0，配套项目主页给出论文与视频。

  1. 学出来的动力学模型：以状态—动作对为输入，预测下一状态与奖励，作为策略优化的 rollout 环境。
  2. 策略优化器：在学到的模型里做 rollout 与策略更新，用大量廉价合成交互替代昂贵的真机交互。
  3. 不确定性估计：对模型预测给出置信度/不确定性，在离线 MBRL 里对不可信区域做惩罚或保守约束，抑制 model bias。
  4. 真机迁移接口：把仿真里优化出的策略部署到真实机器人，验证闭环表现。

这条结构与「视频世界模型」的差别在评价口径：RWM 的输出是状态转移而非像素，下游接的是策略优化与真机成功率，不是 FVD。

# 伪代码：带不确定性惩罚的模型 rollout
def model_rollout(dyn, policy, s0, H, beta):
    s, traj = s0, []
    for t in range(H):
        a = policy(s)
        s_hat, r_hat, unc = dyn.predict(s, a)   # unc：模型不确定性
        r_penalized = r_hat - beta * unc        # 保守惩罚，抑制 model bias
        traj.append((s, a, r_penalized))
        s = s_hat
    return traj

评价这类工作应看三类指标，而不是生成质量：

  • 模型预测精度：留出轨迹上的状态转移误差，尤其是多步 rollout 后的累积误差；
  • 不确定性校准：不确定性与实际预测误差是否单调相关（可用可靠性图 / 分位数覆盖检验）；
  • 真机闭环表现：策略在真实机器人上的成功率、样本效率与安全性。

注意

  • 神经网络仿真器的外推能力有限：策略一旦学会往模型失真区域走，模型内高分与真机表现会迅速脱钩，这正是第二篇论文要解决的问题。
  • 离线数据集的状态覆盖决定上限；数据没覆盖到的区域，不确定性估计也未必可靠。
  • 真机结果依赖具体本体与任务，跨本体迁移需重新校准动力学模型。

对比视频世界模型（如 os242 NVIDIA Cosmos）：Cosmos 是平台级底座，输出观测、支持与外部求解器对接；RWM 更专注「状态转移 → 策略优化」这一条链路，评价口径是真机成功率而非视频质量。

对比无模型 RL：无模型方法直接用真机/仿真交互，样本效率低但不受模型偏差影响；RWM 用学出来的模型换样本效率，代价是必须显式治理 model bias。

对比本站 os244 EMERGE-Policy：EMERGE-Policy 关注的是多个组件如何组织成「机器人心智」的结构层；RWM 提供其中一个可替换的组件——可查询的世界/动力学模型。两者可以放在同一张架构图里读。

对比 reinforcement-learning 模块：模块里讲 PPO / SAC / 离线 RL 的算法原理，RWM 是这些算法在「学出来的环境」里落地时的工程实现与风险治理。
