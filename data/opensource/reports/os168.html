核心矛盾：能力最强的空间推理方案，恰恰是部署代价最高的方案。

空间编码智能体（让 MLLM 写几何脚本并执行）的效果好，是因为它把精确计算外包给了确定性代码——大模型不擅长算，但擅长决定「该算什么」。问题是这条链路在推理时要走完：生成代码 → 起沙箱 → 执行 → 回收结果 → 再生成。每一步都是延迟与失败点。

SpatialOPSD 的思路是「训练时贵、推理时便宜」。 训练阶段照常用昂贵的智能体链路，但把它的执行轨迹摘要化后当作特权信息喂给学生模型。學生是免工具的独立 MLLM，训练目标就是模仿老师的几何表征。推理时老师完全不出现——单次前向搞定。

为什么需要 Repetition-Aware Distillation：这是本工作最有工程价值的部分。特权信息泄漏会让模型学到一种「捷径」——不去真正理解空间关系，而是模仿老师输出里的表面模式，表现为退化的重复文本循环。朴素蒸馏下这个问题很严重。作者的解法是双重约束：重复掩码直接屏蔽已生成片段的再次出现，unlikelihood 正则则从损失层面惩罚重复 token。两者配对后重复幻觉下降 86.4%。

对具身场景的意义：机器人上的算力与实时性约束远比云端严苛。把「能力外包给代码」换成「能力内化进权重」，是用一次性的训练成本换每次推理的确定性——这笔账在高频控制回路里非常划算。

特权指导

老师执行轨迹摘要为 $\tau^{\text{sum}}$，学生模仿其几何表征：

$$ \mathcal{L}{\text{distill}} = \mathbb{E}\big[ \text{KL}\big(p{\text{teacher}}(\cdot \mid o, \tau^{\text{sum}}) \, | \, p_{\text{student}}(\cdot \mid o)\big) \big] $$

Repetition-Aware Distillation

$$ \mathcal{L} = \mathcal{L}{\text{distill}} + \lambda \, \mathcal{L}{\text{unlikelihood}}, \qquad \mathcal{L}{\text{unlikelihood}} = - \sum{t \in \mathcal{T}{\text{rep}}} \log\big(1 - p\theta(y_t \mid y_{<t})\big) $$

配合重复掩码 $\mathcal{M}_{\text{rep}}$ 在 attention / logits 层面直接屏蔽重复片段。

推理

$$ \hat{y} = \text{MLLM}_{\text{student}}(o), \quad \text{无代码生成、无沙箱、无外部执行} $$

重复率监控

'''
监控生成中的退化重复：连续 n-gram 重复占比
'''
def repetition_rate(tokens, n=4):
    grams = [tuple(tokens[i:i + n]) for i in range(len(tokens) - n + 1)]
    if not grams:
        return 0.0
    seen, dup = set(), 0
    for g in grams:
        if g in seen:
            dup += 1
        seen.add(g)
    return dup / len(grams)

排错要点

  • 学生只会抄答案不学推理：轨迹摘要写得太「结论化」，需保留中间步骤与失败修正
  • 重复率降不下来：只加了掩码没加 unlikelihood，或 $\lambda$ 太小
  • 任务指标随重复率一起掉：$\lambda$ 过大抑制了必要的合法重复（如坐标列举），需扫参
  • 延迟没降下来：检查推理路径里是否残留了外部工具调用分支
