NVIDIA/SkillEvaluator 是给 Agent 技能与插件做「装了有没有用」体检的开源框架，2026-11-13 发布 v0.9.0、11-17 仍有推送，Apache-2.0，约 2843 star，主语言 Python。

团队积累了大量 Agent 技能之后，常见困境是说不清哪些该留、哪些只是增加 token 开销。SkillEvaluator 把这个问题变成一个可复跑的对照实验：同一任务跑两遍，一遍带技能、一遍不带，对照质量门槛与花费，判断技能带来的提升是否值得它的成本。0.9 版新增预算控制与版本前后对比，框架还提供分层评估、语义重叠检测与合成评测数据集生成。

  1. 成对执行器：同一任务、同一输入、同一预算下分别跑「带技能」与「不带技能」两条执行路径，只让技能这一个变量变化。
  2. 质量门槛：由使用者自定义判定函数（通过率、正确率、格式合规等），框架不预设什么叫「好」。
  3. 成本记账：记录 token 用量、调用次数与耗时，与质量提升一起进入结论，而不是只报质量。
  4. 预算控制（v0.9）：给对照实验设上限，避免评估本身花掉过多推理预算。
  5. 版本前后对比（v0.9）：同一技能改版前后可跑同一组任务，形成纵向对照。
  6. 辅助模块：语义重叠检测（判断两个技能是否在做同一件事）、合成评测数据集生成、分层评估结果汇总。

这个结构本质上是把 /learn/vla-models 里讲的配对设计搬到了 Agent 技能层：同任务、同种子、只变一个变量，再看差值与区间。

  • 框架本身为 NVIDIA 工程开源项目，无同名论文；方法学来源是配对对照实验与带成本约束的消融分析。
  • ESI: An Embodied Self-Improvement Flywheel for LLM-VLA Agents（arXiv 2611.18176，本轮 p379）：把共享技能接口列为可联合后训练的对象，说明技能不是固定胶水层。
  • Joint World Action Models through Differentiable Trajectory Optimization（arXiv 2611.17626，本轮 p377）：同样强调同时报效果与部署开销。
  • 延伸阅读：/learn/embodied-agent 的 Harness 层、/learn/vla-models 的评估基准与系统性测试方法（配对设计、置信区间、多重比较）。
  1. 安装后先写一个最小质量门槛函数，例如「输出 JSON 可被解析且字段齐全」，跑通一次成对对照，确认两条路径确实只在技能上不同。
  2. 准备一组覆盖技能典型用途与无关用途的任务：只在典型用途上提升、在无关用途上不退化，才算真有用。
  3. 打开成本记账，把质量提升换算成「每提升一个百分点花多少 token」，这比单看通过率更能决定技能去留。
  4. 设预算上限后重跑，确认结论在预算收紧后仍然成立。
  5. 用语义重叠检测扫一遍已有技能库，先把功能重复的技能合并，再逐个评估；否则对照实验会把重复技能的收益算到单个技能头上。
  6. 接入具身任务时，把自定义质量门槛换成「真机或仿真回合成功率」，并固定随机种子与初始布局，与 /learn/vla-models 的配对评估方法保持一致。

注意：对照跑法天然多花一份推理开销；质量门槛定义不当会让整个评估失去意义。
