# Minimal scaffold: compare a pretrained urban navigator against a
# from-scratch control under identical point-goal episodes.
def eval_navigator(policy, episodes, arrive_radius=2.0, timeout_s=120):
    success, spl = [], []
    for ep in episodes:
        traj = policy.rollout(ep)
        arrived = ep.dist_to_goal(traj[-1]) <= arrive_radius and traj.t <= timeout_s
        success.append(float(arrived))
        spl.append(ep.spl(traj, arrived))
    return {'success_rate': sum(success) / len(success),
            'spl': sum(spl) / len(spl)}

对「从网络视频学导航」这类方法，该核对四项：

  1. 净增益：去掉网络视频预训练、只留目标本体数据后成功率掉多少，这是路线成立与否的唯一硬判据；
  2. 分布外衰减：换城市、换季节、换光照后的性能下降幅度，视频预训练买的到底是泛化还是记忆；
  3. 本体迁移成本：从视频表征到四足/轮式底盘需要多少真机数据适配，这决定了它相比直接采真机数据是否划算；
  4. 评测口径一致性：到达半径、超时、碰撞定义是否与对比方法一致。
