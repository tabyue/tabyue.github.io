class Mind:
    def __init__(self, policy, memory, evaluator, improver):
        self.policy, self.memory = policy, memory
        self.evaluator, self.improver = evaluator, improver

    def step(self, obs, goal):
        ctx = self.memory.retrieve(obs, goal)
        action = self.policy(obs, goal, ctx)
        return action

    def feedback(self, traj, outcome):
        verdict = self.evaluator(traj, outcome)
        self.memory.write(traj, verdict)
        if not verdict.ok:
            self.improver.update_hint(verdict.reason)   # 不重训基座，只改提示/路由

结构层工作的评估不宜只报成功率，建议同时看：

  • 长程任务完成率与失败后恢复率（体现评估/改进回路的价值）；
  • 组件消融曲线：逐个去掉记忆、评估、改进，量化各组件贡献；
  • 跨任务迁移：在一个任务上积累的经验能否被另一个任务复用；
  • 反馈开销：评估与改进带来的额外延迟，是否在可接受范围。
