rzc156/dreamforge 是一个把世界模型「想象」转成机器人策略纠错训练数据的单卡管线，MIT、Python，2026-10-12 创建，约 130 star。

它的定位很克制：不做更炫的视频生成，而是回答一个工程问题——如果世界模型会幻觉，怎么保证由它生成的数据真的能用来纠正策略？仓库给出的答案是可证伪：以 SmolVLA 为策略、LIBERO 为任务集，用 CEM 在世界模型里搜候选动作，再用成对的仿真器回放（paired simulator replays）核验想象结果与真实动力学是否一致，只把被证伪的轨迹对转成纠错样本。

topics 覆盖 embodied-ai、vla、lerobot、libero、world-model、imitation-learning，适合作为数据闭环的动手实验底座。

按仓库描述与此类管线的一般结构，可归纳为五段（结构性归纳，具体以 README 为准）：

  1. 策略快照：加载当前 SmolVLA 检查点，在 LIBERO 任务上采样失败/次优片段，作为「哪里需要纠错」的种子。
  2. 想象搜索：在世界模型里对候选动作序列做 CEM（交叉熵法）搜索，挑出模型认为能改善结果的一段。
  3. 成对回放：把同一初始状态、同一动作序列分别送到世界模型与真实仿真器，得到成对轨迹；这一步是「可证伪」的核心。
  4. 一致性判据：比较两条轨迹的状态/奖励差异，超过阈值即判为模型幻觉，剔除或降权；留下的才是可信的纠错信号。
  5. 数据回灌：把通过核验的轨迹对写成纠错训练样本（LeRobot / LIBERO 格式），增量微调策略，回到第 1 步形成闭环。

第 3–4 步最容易被跳过，也最决定项目价值：没有它们，世界模型只是一个会生成漂亮失败样本的噪声源。

  • DreamForge 仓库 — MIT，单卡可证伪纠错数据管线。
  • SmolVLA — LeRobot 生态的轻量 VLA 策略底座。
  • LIBERO 基准 — 机器人操作终身学习任务集。
  • 本轮 p415 PhysVAM（arXiv 2611.26105） — 不用未来像素、改用未来任务价值引导动作，可作路线对照。
  • 站内 /learn/embodied-data-engineering 数据闭环与主动学习 — 纠错样本如何进入数据闭环。

最小上手路径

git clone https://github.com/rzc156/dreamforge.git
cd dreamforge
pip install -r requirements.txt
  1. 先读 README 确认 SmolVLA 权重、LIBERO 任务与世界模型检查点的获取方式；单卡是设计目标，但显存下限要看实际配置。
  2. 用单个任务、少量种子跑通完整闭环：采样失败片段 → CEM 搜索 → 成对回放 → 一致性筛选 → 生成纠错样本，先确认数据格式与数量。
  3. 做可证伪消融：关掉成对回放、直接把所有想象轨迹当训练数据，比较策略微调后的成功率。这一步能直接验证项目主张。
  4. 记录三笔账：世界模型推理耗时、仿真器回放耗时、纠错样本通过率；判断单卡是否真的够用。
  5. 把生成的样本按 /learn/embodied-data-engineering 的数据契约（schema、时间对齐、分片）整理，便于跨任务复用。

常见坑

  • 把「单卡可跑」理解成「几分钟跑完」：CEM 搜索与成对仿真回放本身都要算力。
  • 一致性阈值设得过松，等于没做可证伪；设得过严，通过率太低、闭环没数据。
  • 只报微调后成功率，不报纠错样本通过率与幻觉比例，无法判断收益来自数据还是来自额外训练。
