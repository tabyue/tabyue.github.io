最小上手路径

git clone https://github.com/Vottivott/microduck-playground.git
cd microduck-playground
pip install -r requirements.txt
  1. 先读 README 确认 MuJoCo / mjlab 版本要求与训练入口脚本名，版本不一致是复现失败最常见的原因。
  2. 用仓库给出的 PPO 配置跑一段短训练，确认奖励曲线形状与作者报告一致（不必跑满）。
  3. 加载随仓库提供的预训练策略做评估，记录步态稳定性与前进速度，作为基线。
  4. 走一遍 ONNX 导出，确认导出后策略输出与原策略数值一致。
  5. 若要做实物，先核对 3D 打印件尺寸、关节限位与仿真模型参数，别把仿真默认摩擦系数直接搬上真机。

常见坑

  • 仿真器或 mjlab 版本不匹配，PPO 曲线对不上就误判为「复现不了」。
  • 只跑训练不看随仓库策略，漏掉最有价值的对照基线。
  • 忽略域随机化范围：仿真里稳、真机上倒，通常先查这里。
  • 约 155 star、新建两个月，硬件装配文档可能不完整，作为教学项目比作为产品依赖更合适。
