Grounded Action Model (GAM) 提出的次序很明确：先定位，再行动。仓库标题即 3D Grounding as a Foundation for Robotics，主张把三维空间中的物体/部位定位能力作为机器人动作生成的公共前置，而不是让每个策略各自在隐式表征里重新学一遍「东西在哪」。

  1. 3D Grounding 前端：接收语言指称与 RGB-D / 多视角观测，输出目标在三维空间中的位置、包围盒或部位掩码。
  2. 空间表征层：把定位结果转成下游可消费的几何量（中心点、姿态、相对关系），而不是只给一个 heatmap。
  3. 动作基座：以显式几何量为条件生成动作，使「定位错」与「动作错」在日志里可分离。
  4. 下游策略接口：同一套定位结果可被抓取、放置、导航等不同策略复用。

显式化的代价是多一次前向与一次标定，收益是可解释、可复用、可单独评测。这与端到端 VLA 的取舍正好相反。

# 伪代码：把 3D 定位结果作为动作条件
def act_with_grounding(obs_rgbd, instruction, grounder, policy, T_ext):
    box3d, score = grounder(obs_rgbd, instruction)     # 相机坐标系
    if score < 0.5:
        return 'relocalize'                            # 定位不可信时先重定位
    target_base = T_ext @ box3d.center                  # 转到机器人基坐标系
    return policy(obs_rgbd, instruction, target_base)

建议分两层评估，避免把两类错误混在一起：

层 指标
3D Grounding 指称定位准确率、遮挡/杂乱场景下的鲁棒性、跨视角一致性
动作生成 任务成功率，以及「定位正确时」与「定位错误时」的条件成功率
