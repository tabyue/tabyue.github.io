项目概述

LingBot-VLA 2.0 是蚂蚁灵波（Robbyant）2026-07-08 开源的第二代实用 VLA 基座，技术报告 arXiv:2607.06403《From Foundation to Application: Improving VLA Models in Practice》。它和同团队的 LingBot-World 2.0（os133）不是同一个仓库：这边是动作策略，那边是交互式世界模型。

要解决的不是再刷一个仿真榜，而是实验室到真机之间的三段落差：

  1. 跨本体泛化不够 —— 换一条臂就要重训
  2. 动作空间太窄 —— 只会双臂夹爪，不会头 / 腰 / 底盘 / 灵巧手
  3. 时序推理弱 —— 看不到「下一步世界会怎样」

公开物：Apache-2.0 代码 + 6B native-depth 权重（HuggingFace / ModelScope）+ RoboTwin 后训练权重。主干是 Qwen3-VL-4B-Instruct，两个教师模型 LingBot-Depth 与 DINO-Video 做蒸馏。

三个工程轴

① 跨任务跨本体泛化

预训练大约 6 万小时：5 万小时、覆盖 20 种机器人构型（17 家厂商，单臂 / 双臂 / 轮式 / 人形）的真机轨迹 + 1 万小时第一人称人类视频。数据预处理管线相对 1.0 重做，目标是「一脑多机」而不是每个本体一个 head。

② 全身动作空间

动作不再只是双臂。官方把头、腰、移动底盘、灵巧手都放进同一套表示，工程上常被写成 55 维规范动作向量（关节 / 末端位姿 / 夹爪 / 手 / 腰 / 头 / 移动）。这是它和只做桌面臂的开源 VLA 最直观的差别。

③ 预测式动力学（proxy task）

把未来预测做成辅助任务：DINO-Video 提供语义先验，LingBot-Depth 提供几何线索，用来补时序推理。这不是完整世界模型闭环，而是让策略在生成动作时「多看半步」。

快速开始

git clone https://github.com/Robbyant/lingbot-vla-v2.git
cd lingbot-vla-v2
bash tools/create_train_env.sh   # 官方环境：Python 3.12 / PyTorch 2.8 / flash-attn 2.8.3

python3 scripts/download_hf_model.py \
    --repo_id robbyant/lingbot-vla-v2-6b \
    --local_dir ./lingbot-vla

后训练与部署（先从公开 6B 权重出发，不要试图在工作站复现 6 万小时预训练）：

# 按仓库文档把自家数据转成 LeRobot，写好 robot config，算归一化统计
bash train.sh

export QWEN3VL_PATH=/path/to/Qwen3-VL-4B-Instruct
python -m deploy.lingbot_vla_v2_policy \
    --model_path /path/to/posttraining_ckpt \
    --use_compile --use_length 25 --port 8000

RoboTwin 后训练权重：robbyant/lingbot-vla-v2-6b-robotwin（2026-07-25 放出）。

接入自己机器人时先做的三件事

1. 把本体的关节 / 末端 / 夹爪 / 底盘写进 55D 规范向量，用不到的维置零并在 config 里标明
2. 相机命名和训练时一致（腕部 / 头部不要对调）
3. 先在 RoboTwin 或官方后训练脚本上跑通 eval，再上真机
