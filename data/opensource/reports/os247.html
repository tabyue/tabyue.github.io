Spatial-Forcing 是 OpenHelix-Team 的官方实现仓库，覆盖 SLA（Scaling Spatial-Language-Action Model，arXiv 2611.08373 / 本站 p326） 与 Spatial Forcing（ICLR 2026） 这一系列空间智能机器人基座模型。仓库自述为 serial spatial intelligence robot foundation model 的实现。

核心主张很直接：VLA 大多继承 2D 视觉语言预训练的表征，空间监督却常常只在下游任务适配时才补，导致空间理解难以成为可迁移的基座能力。SLA 把冻结 3D 感知模型提供的空间表征，在持续预训练阶段就对齐进 VLA 的中间层视觉嵌入。

仓库 MIT / Python，2026-11-06 活跃推送，约 335 star，创建于 2025-10-11；SLA 分支位于 tree/master/SLA，项目主页在 SLA.github.io。

  1. VLA 骨干：从预训练 $\pi_{0.5}$ 策略初始化，保持原有动作解码路径；
  2. 冻结 3D 感知教师：提供空间表征作为对齐目标，本身不参与梯度；
  3. 特征依赖门控：按输入自适应聚合 VLA 多个中间层的视觉嵌入，决定「该把空间监督打到哪一层」；
  4. 异构几何标注接口：教师侧可利用部分可得的深度与相机标定，RGB 观测始终可用，因此不同数据集不必强行统一标注；
  5. 概率状态 dropout：随机丢弃机器人状态，抑制对示范轨迹的过拟合；
  6. 训练期专用辅助头：门控、投影、对齐损失全部只在训练图里，训练结束后导出纯 VLA 权重。

最关键的架构约束：辅助组件只能通过梯度影响权重，不能通过前向连接进入部署图。因此推理架构与预训练 VLA 完全一致，给现成 VLA 补 3D 空间能力不需要改部署栈。

def train_step(vla, teacher, gate, proj, obs, state, act, spatial_target):
    vis = vla.intermediate_visuals(obs, dropout_state(state, p=0.3))
    loss_act = mse(vla.action_head(vis[-1]), act)
    z = normalize(proj(gate(vis)))
    t = normalize(teacher(obs) if spatial_target is None else spatial_target)
    loss_align = 1 - (z * t).sum(dim=-1).mean()
    return loss_act + 0.5 * loss_align

  • 与本站 os245（Grounded Action Model，把 3D Grounding 做成独立前置层）对照读：GAM 是显式模块化解法，SLA 是隐式表征对齐解法，二者正好是空间能力注入的两种范式。

对比 Grounded Action Model（本站 os245）：GAM 把 3D 定位做成独立、可评测的前置模块，显式输出几何量给动作层，收益是可归因、可复用，代价是多一次前向与标定误差传播；SLA 把空间能力隐式对齐进表征，推理路径零改动，代价是可解释性差、需要持续预训练。这是「显式模块 vs 隐式对齐」的典型取舍。

对比 NVIDIA Cosmos / LongLive（本站 os242 / os246）：那两个是生成侧与世界模型侧的基础设施，SLA 是判别侧策略的空间表征增强，不在同一层。

对比 La-JEPA（本站 p324）：La-JEPA 用冻结 V-JEPA 编码器提供潜空间目标、从零训紧凑策略；SLA 用冻结 3D 感知教师提供几何目标、在已有 $\pi_{0.5}$ 上做持续预训练。二者都遵循「冻结教师 + 训练期辅助目标 + 推理零残留」这一范式，是很好的对照样本。
