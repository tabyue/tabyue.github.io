动作归一化：最容易被忽略的一步

不同本体的关节量纲差异极大（位置是米、角度是弧度、力矩是牛米）。如果直接把原始动作喂给网络，loss 会被大数值维度主导。正确做法是在训练集上统计每个动作维度的均值与标准差并保存，推理时用同一组统计量反归一化。这一步做错的表现是：训练 loss 下降但动作输出接近常数。

"""
VLA 的最小骨架：视觉 token 与语言 token 拼接后出动作。
"""
class MiniVLA(nn.Module):
    def __init__(self, vision, llm, act_dim, chunk=16):
        super().__init__()
        self.vision = vision          # 图像 -> [N, Dv]
        self.proj = nn.Linear(Dv, Dllm)
        self.llm = llm
        self.act_head = nn.Linear(Dllm, act_dim * chunk)
        self.register_buffer('act_mean', torch.zeros(act_dim))
        self.register_buffer('act_std', torch.ones(act_dim))

    def forward(self, img, text_ids):
        v = self.proj(self.vision(img))            # 视觉 token
        t = self.llm.embed(text_ids)               # 语言 token
        h = self.llm(torch.cat([v, t], dim=1))     # 融合
        a = self.act_head(h[:, -1])                # 取末位预测动作块
        return a.view(-1, self.chunk, self.act_dim) * self.act_std + self.act_mean
