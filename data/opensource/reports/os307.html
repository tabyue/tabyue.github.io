它解决的问题很具体：一个已经训好的动作模型（VLA / 动作专家）到了新任务、新本体或新视角，通常要么全量微调（数据、算力、过拟合代价都高），要么直接零样本硬上（成功率明显掉）。SteerAct 走中间路线——用极少量示范在时序维度上对冻结模型做引导（temporal steering），把测试时适应（test-time adaptation）引入机器人动作模型，而不改动基座权重。

值得单独收录的原因在于方向：把「适应」从参数空间搬到推理时的轨迹 / 时序引导空间，与站内 /learn/vla-models 的微调与评估、/learn/imitation-learning 的少样本示教两条线索都能对上；也和本轮 p400 PhyDEX 揭示的预训练鲁棒性不足形成互补——一个从适应侧补，一个从评测侧量。

按仓库定位与论文标题，可以把结构归纳成四层（注意：这是结构性归纳，具体模块划分、引导算子与损失形式以 README 与论文为准）：

  1. 冻结动作模型：预训练好的 VLA / 动作专家作为基座，权重在整个适应过程中不更新，保证已学到的通用技能不被少量新样本破坏。
  2. 少样本示范编码器：把每个新任务的几条成功轨迹编码成任务条件，重点不是记住动作序列，而是抽出「这个任务的时序节奏与目标状态」。
  3. 时序引导模块：在推理时对动作块的生成过程施加引导——例如调整去噪 / 流匹配轨迹的中间状态、动作块长度与块间衔接，使输出向示范的时序结构靠拢。这里的关键词是 temporal：引导作用在时间结构而非单帧动作幅度上。
  4. 测试时适应循环：用新任务上的在线反馈（成功 / 失败、状态偏差）迭代更新引导量，而不回传梯度到基座。

与常见参数高效微调（LoRA / adapter）相比，这四层全程不产生新的可训练权重副本，部署时只需保留一份基座 + 每任务一份很小的引导状态；代价是推理时要多跑引导步，延迟与引导步数成正比。
