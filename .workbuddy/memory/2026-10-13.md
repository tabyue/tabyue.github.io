## 本轮踩坑

- **同文多域名**：`www.163.com/dy/article/X.html` 与 `dy.163.com/article/X.html` 是同一篇，URL 严格查重抓不到，靠 health_check 的同日同事件 3-gram 才拦下。写新闻时同一篇稿件只取一个域名。
- **开源详情 keyPapers 必须是 markdown 字符串**：`tools/gen_os_report.py` 直接把 detail 各字段 join 成 markdown，list-of-dict 会抛 `sequence item N: expected str instance, list found`。生成报告前先转成 `- **[标题](url)** — 说明` 形式。
- **开源条目的 `detail` 不要嵌进 `meta`**：脚本里 `P.append(dict(meta=dict(..., detail=dict(...))))` 会导致 detail 混进 projects 列表；应在入表前 `m.pop('detail')`。
- **P.append(dict( ... )) 的括号数**：`P.append(` + `dict(` + `meta=dict(` + `detail=dict(` 共 4 层，keyPapers 列表闭合后需要 `]))))` 而不是 `])))`。
- **多次调用同一份查重脚本会误判「新增数量」**：本轮 10 条新闻里有 4 条已被 10-10/10-12 两轮收录（Yujin Robot、CCTV 训练场、RoboDojo、边融边投），属正常去重，不是脚本 bug。

## 本轮踩坑（重构）

- **lastUpdated 不能回填模块级值到章节**：会让"🔥 本章已更新"徽章误判全模块 + 污染时间语义。第一版踩了，git checkout 回滚重做。
- **重排脚本不幂等**：order 是相对原始顺序的索引，二次应用会错乱。加 `sectionOrderVersion===2` 保护。
- **learnCache 的 key 有两条路径**：侧栏点击传中文派生 id（如 `ros2-机器人操作系统`），深链接传英文 fileId（`ros2`）。renderLearn 判 active/展开章节列表必须按 `learnFileMap` 反查 fileId 比对，否则深链接时侧栏不展开（既有 bug，本轮修复）。
- **PowerShell 管道会按 GBK 解码 python 的 UTF-8 stdout** → 中文全乱码。诊断脚本一律自己 open(...,'w',encoding='utf-8') 写文件再 Read。
- **python http.server 没有 SPA fallback**，测深链接要自定义 handler（未命中回落 index.html，模拟 GitHub Pages 404.html 行为）。
- playwright-core 可用 `executablePath` 直接驱动本机 Edge（`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`），不用下载浏览器。
