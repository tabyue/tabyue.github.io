## 经验教训（重要）
- **`git push` 在 PowerShell 里拼 `-c credential.helper="!gh auth git-credential"` 会静默 exit 128，且 stdout/stderr 全空**（连续两次）。此时 `gh auth status` 正常、`git ls-remote` 正常，极易误判成认证失败。根因是 PowerShell 5.1 对含空格 + `!` 的 `-c` 参数传递方式；**改用 Python `subprocess.run([...])` 以 argv 列表直接调用同一命令即成功**。以后 push 优先走 argv 列表，不要在 PowerShell 里手写这段 `-c`。
- 诊断输出别用 `>` 重定向（PS 5.1 默认 UTF-16，Read 读不了）；统一用 `Out-File -Encoding utf8` 或 Python 写 UTF-8 文件。
