## 本次踩坑

1. **health_check 新增「news url 重复」硬校验**：同一篇聚合稿被两条新闻同时引用会 FAIL。本次 n383/n384 同用 damodev 一篇、n378/n380 同用 humanoid.guide 一篇。**教训：一条新闻一个独立 URL，聚合稿不能复用**，写之前先备好不同源。
2. **`'''` 外层字符串与 Python 示例代码 docstring 冲突**：DETAILS 里用 `'''` 包 content，内部示例代码也用 `'''`，会提前终止。解法：外层 `"""`，内层 `'''`；注意最后一个字段的闭合是裸 `'''` 行（无逗号），正则 `^'''$` 要单独替换一次。
3. **PowerShell 里 `foreach(...){} | Out-File` 会报「不允许使用空管道元素」**，且 `'''` 传进 `-c` 参数会被 shell 提前截断。诊断脚本一律写成独立 .py 文件再跑。
4. `gh api` 加 `--jq` 在本机返回空，改用 `| ConvertFrom-Json` 正常。
