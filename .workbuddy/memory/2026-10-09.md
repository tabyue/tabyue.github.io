## 本轮新增经验
- **git push 失败新解法（2026-10-09）**：本机 `git credential-manager` 子进程会静默崩溃（exit 128，无任何报错，GIT_TRACE 停在 `run_command: 'git credential-manager get'`）。之前记录的内存里的 `-c credential.helper="!gh auth git-credential"` trick **已失效**。
  可用解法：`GIT_CONFIG_GLOBAL`/`GIT_CONFIG_SYSTEM` 指向一个空配置文件绕开所有 credential helper，token 直接嵌在 URL 里推送，且需 `dangerouslyDisableSandbox: true`：
  ```
  $env:GIT_CONFIG_GLOBAL="$env:TEMP\gitempty.cfg"; $env:GIT_CONFIG_SYSTEM="$env:TEMP\gitempty.cfg"
  git -c http.sslBackend=schannel push "https://tabyue:$(gh auth token)@github.com/tabyue/tabyue.github.io.git" main
  ```
