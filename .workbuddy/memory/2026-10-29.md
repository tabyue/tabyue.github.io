## 新坑（本轮首次遇到）
- **`gh api search/repositories` 走 subprocess 会挂死**（本轮 6 查询脚本跑 8 分钟无输出，只能 kill）。
  改用 `urllib` 直接调 `https://api.github.com/search/repositories`，带 `Authorization: Bearer $(gh auth token)`，
  4 个查询全部秒回。**以后批量搜 GitHub 一律用 urllib，不要 subprocess 调 gh**。
- **同一仓库会被另一个自动化并行推送**（本轮 remote 多了 /geo/ /bio/ 互动课件 4 个提交）。
  开工 `git status -sb` 干净也可能 push 被拒，被拒时 `fetch + rebase FETCH_HEAD` 即可（改动路径不重叠时无冲突）。
- **`learning-path.json` 在 `data/` 根不在 `data/learn/`**（旧坑复现）：脚本里 `load('data/learning-path.json')`，
  且 lp bump 要放在「章节已存在则跳过」的分支**之外**，否则幂等重跑时 lastUpdated 不会被同步。
- 写 learn 正文时外层用 `r'''`，**代码块里的 Python docstring 必须用 `"""`**（用 `'''` 会提前闭合外层字符串，
  报错是 `IndentationError: unexpected indent`，位置在 docstring 正文行，离真正原因很远）。
- 新增章节的 `estimatedMinutes` 用 `round(chars/400)`（站点 400 字/分钟口径），不要用 ~113 字/分钟的老口径。
