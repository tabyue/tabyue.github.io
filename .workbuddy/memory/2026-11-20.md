## 经验教训（重要）
- **含 LaTeX 的 JSON payload 必须双写反斜杠**：`_p_pdetail.json` 首版既含未转义的真实换行（控制字符），又含 1 处单反斜杠 `\mathcal`；`json.load` 依次报 `Invalid control character` 与 `Invalid \escape`。修法是先逐字符扫描把非法反斜杠双写、再以 `strict=False` 解析并重新 `json.dump` 规范化。以后含数学公式的正文一律用独立 `.md` 暂存再注入，不直接写进 JSON 字符串。
- **正文示例代码必须实跑，数值结论以实测为准**：本轮 15 段代码用 venv（torch 2.14.1+cpu）实跑，13 PASS / 2 SKIP（cupy/numba 需 GPU）。据此修正 7 处与实测不符的表述——Roofline 段误称「两项 GB/s 接近」、SIMT 概念示意伪代码被标成可执行 Python 导致 NameError（改标纯文本）、重力补偿演示打印了不受影响的 x 分量导致「完全跑飞」结论站不住（改打印 z 分量，实测 44.292 m）、FP16 误称「后两项都归零」（实际 3e-8 被量化到 6e-8、只有 6e-9 归零）、捷联漂移「数十米」（实测 15.41 m）、姿态解算与 ESKF 的数值口径。
- **`learning-path.json` 是 `stages[].modules[]` 嵌套**，不是顶层 `modules`；按模块英文 id 匹配 lastUpdated 时必须遍历 stages，否则断言命中 0。
- **注入脚本要支持「替换」而非只追加**：正文修正后需按首行 marker 定位旧块、以两个换行加练习标题为右边界精确整块替换；幂等跳过会把旧内容留在库里。
- **PowerShell 拼 `credential.helper="!gh auth git-credential"` 会静默 exit 128**，push 一律改 Python `subprocess.run([...])` argv 列表直调；清理临时文件必须精确列名，不能用 `git clean`（会误删正式新增的 `data/opensource/os*.json` 与 `data/papers/p*.json`）。
