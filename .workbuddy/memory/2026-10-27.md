## 新坑
- **`tools/test_learn_ui.cjs` 里硬编码了章节总数**（`assert.deepEqual(counts, { stages: 7, modules: 32, chapters: 539 })` + 用例名里的「539章」）。每次新增学习章节后这个用例必然 FAIL，需同步改成新数字（本轮 539 → 541）。这是预期行为，不是真 bug——报错形如 `+ chapters: 541, - chapters: 539`。
- **二次深化脚本写报告文件时若 PowerShell 同时 `Out-File` 同名文件会 PermissionError**：脚本末尾不要写与 shell 重定向目标同名的文件（本次脚本逻辑已执行完、JSON 已写盘，只是报告没落盘）。改成不同文件名即可。
- **PowerShell 重定向 `>` 输出是 UTF-16**：解析 node 输出的 JSON 时要按 utf-16 解码再 `s[s.find('{'):]` 截取，直接 utf-8 会 UnicodeDecodeError。
- 学习正文单次写入容易只有 4K 出头（比模块平均 6.9K 薄）。用「二次追加」在「能力自检」小节**之前**插入新小节、并把该小节序号顺延（六→八 / 八→十），幂等守卫用「目标标题是否还存在」判断即可。

## 新经验
- **并行编辑代理反复读写同名临时文件会被判为死循环而中断**（两个代理因此半途而废）：委派时必须规定专属前缀 + 每次导出不同文件名 + 小步写盘。
- 子代理写回 JSON 要先检测原文件 CRLF/LF 并保持，否则 diff 变成整文件。
- 体检脚本每次运行覆盖共享报告，多代理并行时报告只反映最后一次运行，汇总前要全量重跑。
