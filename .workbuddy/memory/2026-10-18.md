## 新踩到的坑

- **news/papers/jobs 的列表是「最新在前」**：`items[-40:]` 取到的是最老的 40 条，查重导出要写 `items[:40]`。
- **`gh api` 在 PowerShell 里不能内联带 `&` 的 URL、也不能内联带空格的 `--jq` 表达式**（参数被拆分，报 `无法加载模块 stars=`）。一律写成 .py 用 `subprocess.run(['gh','api',...])` 再落盘。
- **urllib 直连 api.github.com 会 403 rate limit**（未认证）。验证 repo 元数据优先走 `gh api`（已认证）。
- **Write 工具写入的 Python 文件偶发丢字符**：本次 `_upd_papers.py` 里 `。'''` 被写成 `。'`（少了两个引号），报 `SyntaxError: invalid character '—'`。写完长脚本后若报莫名的 SyntaxError，先 Read 报错行附近确认定界符完整。
