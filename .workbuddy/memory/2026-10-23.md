## 本轮新经验
- **`gh api search/repositories` 必须显式 `-X GET`**：不指定时只要带 `-f` 参数就会切到 POST，返回 `Not Found (HTTP 404)`。正确写法：`gh api -X GET 'search/repositories?q=...&sort=stars&per_page=30'`（URL 里的 `&` 在 Python subprocess 中安全，PowerShell 内联才需要回避）。
- **Python 单引号字符串里不能出现裸 `'`**：写论文正文时 `$A^{(i)}_{t'}$`（LaTeX 撇号）和示例代码 `` `pick(obj, approach='top')` `` 都会提前闭合外层 `'...'`，报错表现为 `SyntaxError: invalid syntax. Perhaps you forgot a comma?`，且 caret 指向一大段无关位置。改用 `_{t2}` 和 `approach="top"`（代码块内允许 ASCII 双引号）。**排查方法：报错行附近搜 `'`**。
- **选题查重命中率仍然高**：Minerva Humanoids 排爆人形早在 10-06 就以 n380 收录（另一域名 roboticfirms.com），靠 title[:18] 前缀比对拦下。开源候选里 DUP 率约 30%（IsaacLab / RLinf / every-embodied / dora / ProtoMotions / horus / robonix / XPolicyLab / flux-action / omnisim 等）。
