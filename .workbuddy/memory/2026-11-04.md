## 本轮新踩的坑（已记入 automation-5 记忆）

1. **PowerShell 数组切片 `1..0` 陷阱**：`foreach` 批量跑校验脚本时，用 `$arg[1..($arg.Length-1)]` 处理「无参数」脚本会返回 `@($null, $arg[0])`，把脚本名当多余参数传进去 → `normalize_learn.py` / `health_check.py` / `audit_learn_content.py` 报 usage 错误、`sync_learn_split.py` 只处理 0 个真实模块并显示 `[skip] src not found`。改为显式逐条 `& python tools/xxx.py` 调用。
2. **`audit_learn_content.py` 会校验 `section['chars'] == len(content)`**（unittest 也有此断言）：改正文后只改 content 不改 chars 会让 unittest 1 项失败。顺手修公式时务必同步 `chars`。
3. **`[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` + `$env:PYTHONIOENCODING='utf-8'`** 一起设置，PowerShell 管道到 `Out-File -Encoding utf8` 才不会把中文写成 mojibake；更稳的做法是让 Python 脚本自己写 UTF-8 报告文件。
