打个比方 一对“反着用”的双胞胎

玩具里的小电机，接上电池它就转；反过来用手飞快地拧它的转轴，两端接上灵敏电流计，指针也会偏。同一台机器，电→动就是电动机，动→电就是发电机，只是能量换了个方向流。

想明白为什么 通电的线圈为什么会自己转起来

从一根导线开始，一步一步搭出一台电动机。

  1. 电流周围有磁场

    在小磁针上方平行放一根导线，一通电，小磁针就偏转；电流反向，偏转方向也反过来。这是奥斯特发现的电流的磁效应：电能生磁。

  2. 绕成螺线管，磁场叠加

    把导线一圈圈绕起来，每一圈的磁场叠在一起，外面的磁场就和条形磁体一样，一端 N、一端 S。哪端是 N 由电流方向和绕法共同决定，用安培定则判断。

  3. 磁场对电流有力的作用

    把通电导线放进磁场，导线会被推动。只改电流方向，或只改磁场方向，力就反向；两个一起改，力的方向不变。

  4. 线圈两边受力方向相反

    线圈的 ab 边和 cd 边电流方向相反，受的力也相反，一推一拉，线圈就转了。转到线圈平面和磁感线垂直的位置（平衡位置），两个力在一条直线上，就不再推它转了。

  5. 换向器让它一直转

    每当线圈刚转过平衡位置，换向器就自动把线圈里的电流方向反过来，受力也跟着反向，线圈就能沿原方向继续转下去。

所以电动机走的是“电 → 磁 → 力 → 转”。把这条路倒过来，让导体在磁场里切割磁感线，就能“转 → 电”，这就是法拉第发现的电磁感应，也是发电机的原理。

要记住的几件事

磁体和磁场

磁体有 N、S 两个磁极，同名磁极相互排斥，异名磁极相互吸引。小磁针静止时 N 极所指的方向就是那一点的磁场方向。磁感线是为了描述磁场画出来的假想曲线，磁体外部从 N 极出来、回到 S 极。

地磁场

地球本身就是个大磁体。地磁北极在地理南极附近，地磁南极在地理北极附近，所以指南针的 N 极指向地理北方。两组极并不完全重合，我国宋代沈括最早记述了这一现象。

电生磁与电磁铁

1820 年丹麦物理学家奥斯特发现通电导线周围有磁场。电磁铁的磁性有无可以用通断电控制；电流越大、匝数越多，磁性越强；插入铁芯，磁性大大增强。

电动机与发电机

电动机：通电线圈在磁场中受力转动，电能转化为机械能。发电机：1831 年英国物理学家法拉第发现电磁感应，闭合电路的一部分导体在磁场中做切割磁感线运动时产生感应电流，机械能转化为电能。

! 最容易错的地方

先看装置里有没有电源：有电源、导线放在磁体中间的，是“磁场对电流的作用”（电动机）；没有电源、接着电流表的，是“电磁感应”（发电机）；导线旁边放小磁针的，是奥斯特实验。另外，电路断开，或者导体顺着磁感线方向运动（没有切割），都不会产生感应电流。

中考怎么考 深圳理化合卷中物理占 70 分，电与磁常在作图题和辨认实验装置的选择题里出现

  • 选择题：给出几幅实验装置图，分辨奥斯特实验、电磁感应实验和“磁场对电流的作用”实验；或者问扬声器、动圈式话筒、电磁起重机分别用了哪个原理。
  • 作图题：用安培定则标出螺线管的 N、S 极、电源的正负极，或者小磁针静止时的指向；画磁感线别忘了标箭头。
  • 实验题：探究影响电磁铁磁性强弱的因素。用吸起大头针的数目来反映磁性强弱（转换法），每次只改一个量、其他量保持不变（控制变量法）。
  • 实验操作考试：深圳理化实验操作单独计 20 分（物理 10 分），连接电路是基本功：连线时开关先断开，电流表要串联、电流从正接线柱流入。
典型设问　用电池、滑动变阻器和电磁铁串联做实验，把滑片向某一方向移动，使变阻器接入电路的电阻变小。电磁铁吸起的大头针数目会怎样变化？
怎么想　电阻变小，电压不变，由欧姆定律知电流变大；匝数和铁芯都没变，电流越大磁性越强，所以吸起的大头针变多。这类题的思路链是“电阻 → 电流 → 磁性 → 现象”，一环扣一环往下推。
