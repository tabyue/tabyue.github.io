打个比方 声音要人传话，电磁波自己会跑

声音像排队传话，要靠空气分子一个碰一个往外传；空气抽走了，没人传话，声音就出不去。电磁波不需要“传话的人”，在空无一物的太空里照样跑得飞快。所以宇航员在舱外不能直接喊话，要靠无线电通话。

想明白为什么 为什么波长越短，频率就越高

公式 c = λf 不用死记，想清楚“一秒钟波跑了多远”就够了。

  1. 波长 λ：一个波有多长

    相邻两个波峰（或两个波谷）之间的距离叫波长，单位是米（m）。

  2. 频率 f：一秒钟来几个波

    一秒钟内经过某一点的完整波的个数叫频率，单位是赫兹（Hz）。1 kHz = 103 Hz，1 MHz = 106 Hz，1 GHz = 109 Hz。

  3. 一秒钟跑了多远

    一秒钟里经过 f 个波，每个波长 λ，波就往前跑了 λ × f 米。一秒钟跑的路程就是波速，所以 c = λf。

  4. c 是个定值

    不管哪种电磁波，在真空中的速度都是 3×108 m/s（和光速一样）。c 不变，λ 和 f 就“此长彼短”：波长越短，频率越高。

  5. 不需要介质

    电磁波能在真空中传播。太阳光穿过真空到达地球，路上大约要 8 分钟；声音却必须靠空气、水、固体这些介质才能传播。

所以波谱上从左到右，只是同一种东西的波长越来越短、频率越来越高；用途不同，是因为不同波长的电磁波“性格”不同。

要记住的几件事

电磁波

导线中电流迅速变化，就会在周围空间激起电磁波。电磁波能在真空中传播，真空中的波速 c = 3×108 m/s。光也是一种电磁波。

电磁波传递信息

广播、电视、移动通信都靠电磁波传递信息。手机既是无线电发射台，又是接收台。卫星通信用微波，光纤通信用光在光导纤维里传播。

能源怎么分

能从自然界直接获取的是一次能源（太阳能、煤、石油等）；要消耗一次能源才能得到的是二次能源（电能、汽油等）。能源源不断得到补充的是可再生能源（太阳能、风能、水能）；短期内不能补充的是不可再生能源（煤、石油、天然气、核能）。

能量转化有方向

能量的转化和转移具有方向性：热量会自动从高温物体传到低温物体，反过来却不会自动发生；汽车刹车时机械能变成内能散到空气里，这些内能不会自动变回来再推动汽车。

! 最容易错的地方

“能量是守恒的，为什么还要节约能源？”因为能量转化有方向性：用过之后，能量大多变成散失到周围的内能，总量没少，却很难再被利用。另外别搞混：电能是二次能源；核能是不可再生能源；核电站用的是核裂变，太阳内部是核聚变。

中考怎么考 深圳理化合卷中物理占 70 分，这两章多以选择题、填空题出现，计算题要特别注意单位换算

  • 选择题：判断某个设备用的是电磁波还是声波（如倒车雷达用超声波、手机用电磁波）；电磁波能否在真空中传播；不同电磁波的速度是否相同。
  • 计算题：用 c = λf 求波长或频率。先把 kHz、MHz、GHz 换成 Hz，再代入公式。
  • 能源辨析：给出一串能源，分出一次 / 二次、可再生 / 不可再生；判断核电站用的是裂变还是聚变。
  • 情景题：结合太阳能电池、风力发电、新能源汽车等，说出能量是怎样转化的，比如太阳能电池把太阳能转化为电能。
典型设问　家用微波炉使用的电磁波频率约为 2450 MHz，它的波长大约是多少？
怎么想　先换单位：2450 MHz = 2.45×109 Hz。再由 c = λf 得 λ = c ÷ f = 3×108 m/s ÷ 2.45×109 Hz ≈ 0.12 m，也就是约 12 cm。把滑块拖到微波区域，能看到同样的结果。先统一单位，再代公式，指数部分最容易算错，要多看一眼。
