打个比方 像切披萨

一块披萨就是一个扇形。圆心角占整圆的三分之一，这块披萨的饼边（弧长）和面积就都是整张的三分之一。按比例想，比背公式牢靠。

想明白为什么 圆周角为什么是圆心角的一半

这个结论能证，而且证法只用到等腰三角形和外角定理。

  1. 先看一边过圆心的特殊情形

    设圆周角 ∠BAC=α，其中 AB 过圆心 O。连 OC，因为 OA=OC，△OAC 是等腰三角形，所以 ∠OCA=α。

  2. 用外角定理

    ∠BOC 是 △OAC 的外角，等于不相邻两内角之和：∠BOC=α+α=2α。特殊情形证完。

  3. 一般情形拆成两个特殊情形

    过顶点 A 作直径，它把圆周角分成两个「一边过圆心」的角。对每一半用上面的结论，再相加（圆心在角内）或相减（圆心在角外）即可。

  4. 于是同弧圆周角处处相等

    同一条弧所对的圆心角只有一个，而每个圆周角都等于它的一半，所以同弧（或等弧）所对的圆周角全都相等。

  5. 直径所对的圆周角是 90°

    此时圆心角是平角 180°，一半正好 90°。反过来，圆中出现直角就该去找直径 —— 这是构造直角、使用勾股定理的常用入口。

所以圆里看到角先找同弧，看到直角先找直径，看到切线先连半径。大多数圆的题就是从这三句开始的。

要记住的几件事

垂径定理

垂直于弦的直径平分这条弦，并且平分弦所对的弧。推论：平分弦（不是直径）的直径垂直于这条弦，并且平分弦所对的弧。计算时连半径：半径 r、弦心距 d、半弦长构成直角三角形，r² = d² + (弦长/2)²。例如 r = 5、d = 3，半弦长 4，弦长 8。

圆周角是圆心角的一半

同弧（或等弧）所对的圆周角相等，都等于圆心角的一半。

直径所对的圆周角是直角

反过来，90° 的圆周角所对的弦一定是直径。常用来证直角或找直径。

d 与 r 比大小定位置

d < r 相交、d = r 相切、d > r 相离。切点处半径垂直于切线。

切线长定理

从圆外一点 P 引 ⊙O 的两条切线，切点为 A、B，线段 PA、PB 的长叫切线长。定理：PA = PB，并且 PO 平分 ∠APB。理由：连 OA、OB，OA ⊥ PA、OB ⊥ PB，OA = OB，PO 公共，由 HL 得 △OAP ≌ △OBP。

弧长和扇形面积按比例算

圆心角占 n/360，弧长就占周长的 n/360，面积占圆面积的 n/360。扇形面积也等于 ½lr。

! 最容易错的地方

弧长公式写成 nπr²/180、面积写成 nπr/360——两个公式记串了。不用硬背：先算这个扇形占整圆的几分之几，再乘周长 2πr 或面积 πr²，怎么都不会错。

中考怎么考 几何大题的重要载体，切线证明必考

  • 选择题／填空（3 分）：圆周角定理、弧长与扇形面积计算。
  • 证明题（8–10 分）：证明某直线是圆的切线——这是圆的头号考点。
  • 证切线两种方法：① 已知点在圆上，连半径证垂直；② 不知点是否在圆上，作垂线证距离等于半径。
  • 易错点：弧长与扇形面积公式记串；圆周角定理忘了「同弧」这个前提。
典型设问　⊙O 中 AB 是直径，C 是圆上一点，过 C 作 CD ⊥ AB 于 D。若 AD = 2、BD = 8，求 CD 的长。
怎么想　AB 是直径，所以 ∠ACB = 90°（直径所对的圆周角是直角）。在直角三角形中，斜边上的高满足 CD² = AD · BD = 2 × 8 = 16，CD = 4。看到直径就想直角，看到斜边上的高就想射影关系。
