打个比方 三角形像三角支架

相机三脚架一旦撑开就很稳，推不变形，因为三边定了形状就唯一确定（SSS）。而四边形的门框容易被推歪，所以要加一根斜撑，把它变成两个三角形。

想明白为什么 SSS 能判全等，SSA 为什么不能

判定条件够不够用，有个硬标准：照它作图，能不能作出形状不同的三角形。

  1. 三角形的稳定性

    三条边定好，形状就无法再改动；四边形却能被推歪。这就是三边相等即全等的直观原因，也是桥梁、屋架都用三角形的原因。

  2. SSS 用作图验证

    先画出 BC。以 B 为圆心、AB 为半径画弧，以 C 为圆心、AC 为半径画弧，两弧在 BC 同侧只有一个交点，三角形唯一确定。

  3. SSA 当场露馅

    已知 ∠B、边 AB 和对边 AC。以 A 为圆心、AC 为半径画弧，这条弧可能与 BC 所在射线交于两点，得到一个锐角三角形和一个钝角三角形 —— 两者形状不同，所以不能判定。

  4. 直角三角形为什么能用 HL

    直角已经把「钝角那一种可能」排除了，弧与射线只剩一个交点。所以斜边加一条直角边就够，HL 是 SSA 在直角情形下的特例。

  5. 三角形三边关系同源

    两边之和必须大于第三边，否则两段圆弧根本交不上，三角形作不出来。「2、3、6 能否构成三角形」问的就是这件事。

所以遇到没学过的判定组合，别凭感觉，动手按它作一次图：能作出两个不同的，这个条件就不成立。

要记住的几件事

两边之和大于第三边

只需验证最短两边之和是否大于最长边。已知两边 a、b 时，第三边范围是 |a−b| < x < a+b。

内角和永远是 180°

不管三角形多大多扁，三个内角加起来都是 180°。所以已知两角就能求第三角。

判定全等有四招

SSS、SAS、ASA、AAS。直角三角形还多一招 HL（斜边和一条直角边）。

SSA 和 AAA 不行

SSA 可能画出两个不同的三角形；AAA 只能说明形状相同、大小可以不同，那是相似。

! 最容易错的地方

SAS 里的角必须是两边的夹角。如果角不在两边之间（变成 SSA），就可能画出两个不同的三角形，不能判定全等。写证明时一定要检查角的位置。

中考怎么考 全等三角形是几何证明的核心，必考大题

  • 选择题（3 分）：三边关系判断能否构成三角形、内角和计算。
  • 证明题（6–8 分）：证两三角形全等，再由全等推出边或角相等。这是中考几何第一道大题的常见形式。
  • 关键：找全等条件时，公共边、公共角、对顶角是最容易被忽略的隐含条件。
  • 易错点：误用 SSA 或 AAA；书写格式不规范（对应顶点要写在对应位置）。
典型设问　已知 AB = AD，∠BAC = ∠DAC，求证：△ABC ≌ △ADC。
怎么想　三个条件：AB = AD（已知）、∠BAC = ∠DAC（已知）、AC = AC（公共边）。符合 SAS，故全等。看到两个三角形共用一条边，第一反应就是把它写成公共边——这往往是题目故意不给的那个条件。
