打个比方 外角和像绕操场走一圈

沿着多边形的边走一圈回到起点，每到一个拐角就转一个外角，走完正好转了一整圈——360°。边数再多也还是一圈，所以外角和与 n 无关。

要记住的几件事

两点之间线段最短

这是「两点间的距离」的定义依据。而「两点确定一条直线」说的是直线的性质，别混在一起。

中点把线段分成相等两段

C 是 AB 中点 ⟺ AC = CB = ½AB ⟺ AB = 2AC。不管 C 在哪，AC + CB = AB 总成立。

补角比余角大 90°

余角 = 90° − 角，补角 = 180° − 角。两者相差永远是 90°，与原来的角多大无关。

内角和看三角形个数

n 边形被对角线分成 n − 2 个三角形，所以内角和 = (n − 2) × 180°；外角和永远是 360°。

! 最容易错的地方

以为对角线总数就是 n − 3。n − 3 只是一个顶点出发的条数；每个顶点都连，每条又被数了两次，所以总数是 n(n − 3) ÷ 2。六边形是 9 条，不是 3 条。

中考怎么考 角度计算是高频小题，多边形内角和几乎年年考

  • 选择题（3 分）：余角补角、方位角、钟面角。
  • 选择题／填空（3 分）：正 n 边形的内角、外角、对角线条数。
  • 填空题（3 分）：线段中点与线段和差的计算，常设成「已知 AB、求 MN」的套娃题。
  • 易错点：对角线总数要除以 2；内角和与单个内角混淆。
典型设问　一个正多边形每个外角都是 40°，它是几边形？内角和是多少？
怎么想　外角和恒为 360°，所以边数 n = 360 ÷ 40 = 9，是九边形；内角和 = (9−2) × 180° = 1260°。凡是给出每个外角或每个内角求边数，都从外角和 360° 入手最快。
