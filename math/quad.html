一元二次方程

判别式说有没有根，抛物线和 x 轴有没有交点，说的是同一件事。

判别式与交点个数

x² − 2x − 3 = 0

两个不相等的实数根

根：—

配方法：补成一个正方形

虚线那块就是要补上的 (p/2)²。

x² + 6x − 7 = 0

解得：—

长比宽多 4 米

20 ~ 140

打个比方 判别式像考试前的估分

不用真的把卷子做完（解出根），只要算一下 Δ，就能知道「有没有解、有几个解」。Δ 是方程的体检报告。

要记住的几件事

判别式定根的个数

Δ = b² − 4ac。Δ > 0 两个不等实根，Δ = 0 两个相等实根，Δ < 0 无实数根。

配方要加一半的平方

x² + px 配成完全平方要加 (p/2)²，而且两边都加。

公式法最通用

x = (−b ± √Δ) / (2a)。能因式分解时分解更快，分解不了就用公式。

根与系数的关系

x₁ + x₂ = −b/a，x₁·x₂ = c/a。不用解出根也能求两根之和、之积。

! 最容易错的地方

实际问题解出两个根就全写上。长度、宽度、人数不能是负数，必须舍去不符合实际的根。另外解方程前要先检查二次项系数 a ≠ 0，否则它根本不是一元二次方程。
