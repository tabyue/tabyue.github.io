想明白为什么 幂的三条法则，全来自「数一数几个 a」

a³·a² 是 a⁵ 还是 a⁶？忘了不要猜，回到定义现场数一遍。

  1. 同底数幂相乘：指数相加

    a³ 是 3 个 a 相乘，a² 是 2 个。接起来一共 5 个 a 相乘，所以 a³·a²=a⁵。指数是「个数」，个数相加。

  2. 幂的乘方：指数相乘

    (a³)² 是 2 个 a³ 相乘，而每个 a³ 里有 3 个 a，总共 2×3=6 个 a，所以等于 a⁶。

  3. 同底数幂相除：指数相减

    a⁵÷a² 是把分子里的 5 个 a 约掉 2 个，剩 3 个。顺着这条往下，aⁿ÷aⁿ=1 同时又等于 a⁰，所以规定 a⁰=1（a≠0）；a²÷a⁵=1/a³ 就是负指数的来历。

  4. 完全平方公式看面积

    边长 a+b 的正方形，切成左上 a²、右下 b²，另外两块都是 a×b 的长方形。所以 (a+b)²=a²+2ab+b²，中间那个 2 就是两块长方形。

  5. 平方差公式也是面积

    从 a×a 的正方形里挖掉一个 b×b 的角，把剩下的 L 形沿虚线剪开再拼一次，正好是长 a+b、宽 a−b 的长方形。所以 a²−b²=(a+b)(a−b)。

  6. 整式除法只是把乘法倒过来

    单项式除单项式，系数相除、同底数幂的指数相减；多项式除单项式，就是把每一项分别除一次（又是分配律）。所以除法的检验办法也一样：乘回去能还原就对了。

所以法则记混了就退回定义数 a 的个数；乘法公式记混了就画个正方形。这两招从不失效。

要记住的几件事

指数就是「几个因数相乘」

a³ 表示 3 个 a 相乘。所有幂的法则都能从这句话推出来，记不住法则时就展开数一数。

乘法指数加，乘方指数乘

aᵐ·aⁿ = aᵐ⁺ⁿ（合并个数）；(aᵐ)ⁿ = aᵐⁿ（n 组每组 m 个）；aᵐ÷aⁿ = aᵐ⁻ⁿ（约掉）。

完全平方公式有中间项

(a+b)² = a² + 2ab + b²。面积图上一共四块，中间两块长方形就是 2ab。

平方差公式反过来最有用

(a+b)(a−b) = a² − b²。算 102 × 98 这类题时，写成 (100+2)(100−2) 可以心算。

! 最容易错的地方

a³ + a³ 写成 a⁶。加法是合并同类项，结果是 2a³；只有乘法才把指数相加。另外 (2a)³ = 8a³，系数也要乘方，不能只写 2a³。

中考怎么考 幂的运算是计算题的常客，乘法公式贯穿整个初中

  • 选择题（3 分）：幂的四条法则辨析，专挑 a³+a³、(2a)³ 这类坑。
  • 计算题（6 分）：整式乘法化简，常含乘法公式。
  • 简便计算：用平方差算 102×98、用完全平方算 99²，考查公式的灵活运用。
  • 后续影响：乘法公式直接决定下学期因式分解和一元二次方程配方做不做得动。
典型设问　计算：(a + 2b)² − (a + 2b)(a − 2b)
怎么想　前一项用完全平方：a² + 4ab + 4b²；后一项用平方差：a² − 4b²。相减时注意整体变号：(a²+4ab+4b²) − (a²−4b²) = 4ab + 8b²。减去一个整式，括号里每一项都要变号。
