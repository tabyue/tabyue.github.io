打个比方 像电影院找座位

「8 排 12 号」就是一组坐标——先说排（纵），再说号（横），顺序固定才不会坐错。坐标系只是把这件事推广到了整个平面，还允许负数。

想明白为什么 坐标为什么能把几何变成计算

一旦点有了坐标，很多「证明」就变成了「算一算」。

  1. 一一对应是全部的基础

    两条互相垂直的数轴，给平面上每个点配了唯一一对有序实数；反过来每一对数也只对应一个点。有了这层对应，图形就能用数描述。

  2. 对称只看符号

    关于 x 轴对称，横坐标不动纵坐标变号；关于 y 轴对称，纵坐标不动横坐标变号；关于原点对称，两个都变号。不必画图，看符号就行。

  3. 平移就是加减

    右移 a 个单位横坐标 +a，上移 b 个单位纵坐标 +b。「左减右加、下减上加」说的就是这件事。

  4. 距离来自勾股定理

    两点 (x₁,y₁)、(x₂,y₂) 之间作水平和竖直的直角边，长度分别是 |x₂−x₁| 与 |y₂−y₁|，于是距离是 √((x₂−x₁)²+(y₂−y₁)²)。几何量彻底变成了算式。

  5. 面积也能算

    底边在坐标轴上或平行于坐标轴时，底是两个横（纵）坐标之差，高是第三点到这条底的距离 —— 也是坐标之差。所以给三个点就能求面积。

所以几何题卡住时，试着建系给点配坐标：很多需要灵感的辅助线，换成坐标就只剩四则运算。

要记住的几件事

坐标有顺序

(a, b) 先横后纵，(3, 2) 和 (2, 3) 是两个不同的点。

到轴的距离看另一个坐标

到 x 轴的距离是 |纵坐标|，到 y 轴的距离是 |横坐标|。这两个最容易记反。

象限逆时针编号

右上第一、左上第二、左下第三、右下第四。坐标轴上的点不属于任何象限。

三种对称一起记

关于 x 轴 (x, −y)；关于 y 轴 (−x, y)；关于原点 (−x, −y)。谁变号看对称的是谁。

! 最容易错的地方

把「点 P 到 x 轴的距离」算成横坐标。想象从点垂直落到 x 轴，走的是竖直方向，长度当然是纵坐标的绝对值。记一句话：到谁的距离，就看另一个坐标。

中考怎么考 坐标是函数和几何的桥梁，小题必考

  • 选择题（3 分）：象限判断、对称点坐标、点到坐标轴的距离。
  • 填空题（3 分）：由点的象限反推字母的取值范围（常与不等式结合）。
  • 解答题：在坐标系中求三角形面积，用坐标差算底和高。
  • 易错点：到 x 轴的距离是 |纵坐标|；坐标轴上的点不属于任何象限。
典型设问　点 P(a−1, 2a+3) 在第二象限，求 a 的取值范围。
怎么想　第二象限要求横坐标 < 0 且纵坐标 > 0：a − 1 < 0 得 a < 1；2a + 3 > 0 得 a > −1.5。取公共部分：−1.5 < a < 1。象限条件翻译成不等式组，这是坐标与不等式结合的固定套路。
