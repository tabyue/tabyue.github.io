打个比方 像扔出去的篮球

球出手后的轨迹就是一条抛物线：先上升、到最高点、再下落。最高点就是顶点，左右两边对称——所以上升和下降用的时间一样长。

想明白为什么 对称轴 x=−b/2a 是怎么冒出来的

顶点坐标不必背，配一次方就全出来了；而且配完能看清函数与方程的关系。

  1. 从一般式开始配方

    先把二次项和一次项一起提出 a：y=ax²+bx+c = a(x²+(b/a)x)+c。注意 a 不能提丢，否则后面配出来的系数全错。

  2. 补成完全平方

    括号里加上再减去 (b/2a)²：y = a(x+b/2a)² + c − b²/(4a) = a(x+b/2a)² + (4ac−b²)/(4a)。

  3. 平方项非负，最值立刻可见

    (x+b/2a)² 恒 ≥0，且只在 x=−b/2a 时取 0。所以 a>0 时此处取最小值，a<0 时取最大值 —— 这就是顶点，x=−b/2a 就是对称轴。

  4. 三种式子各管一类问题

    一般式看 a、b、c 的符号（a 定开口，c 定与 y 轴交点，−b/2a 定对称轴位置）；顶点式 y=a(x−h)²+k 直接读最值；交点式 y=a(x−x₁)(x−x₂) 直接读与 x 轴的交点。

  5. 函数与方程是一件事

    图象与 x 轴的交点横坐标，就是 ax²+bx+c=0 的根。所以判别式大于 0 两个交点、等于 0 一个、小于 0 没有 —— 上一章的判别式在这里有了图象。

  6. 平移也能从顶点式看出来

    y=a(x−h)²+k 中，h 管左右、k 管上下，开口形状由 a 决定且平移不改变 a。所以「向右平移 2 个单位」就是把 h 加 2，写成 y=a(x−h−2)²+k —— 左加右减只针对括号里的 x，上下平移才是直接加减常数。

所以二次函数题的第一步几乎总是配方或求对称轴。有了顶点与开口方向，图象就被定住了。

要记住的几件事

a 管开口方向和宽窄

a > 0 开口向上有最小值，a < 0 开口向下有最大值；|a| 越大开口越窄。

对称轴 x = −b/(2a)

a、b 同号时对称轴在 y 轴左边，异号在右边，口诀「左同右异」。

c 是与 y 轴交点的纵坐标

抛物线一定经过 (0, c)。

与一元二次方程相通

令 y = 0 就是方程 ax²+bx+c = 0，交点横坐标就是根，交点个数由 Δ 决定。

! 最容易错的地方

求最值时忘了检查取值范围。围栏问题里 x 必须满足 0 < x < 20；如果实际问题限定 x 只能取整数或某个区间，最值可能不在顶点处，要在区间端点再比一比。

中考怎么考 中考压轴题的常客，分值最高

  • 选择题（3 分）：由图象判断 a、b、c 的符号，或判断 a+b+c 的正负（代 x = 1）。
  • 解答题（8–10 分）：求表达式、求顶点、求最值。
  • 压轴题（10–12 分）：与几何结合——抛物线上存在点使三角形面积最大／为直角三角形／为等腰三角形。
  • 易错点：实际问题忽略自变量范围；顶点式与一般式转换出错。
典型设问　某商品每件成本 20 元，售价 x 元时日销量为 (100 − 2x) 件，求日利润最大时的售价。
怎么想　利润 W = (x − 20)(100 − 2x) = −2x² + 140x − 2000。顶点 x = −b/(2a) = 140/4 = 35 元，最大利润 W = 450 元。还要检查范围：销量 100−2x > 0 得 x < 50，售价 x > 20，35 在范围内，有效。
