打个比方 像把门槛拆了再进屋

原方程有个门槛：分母不能为 0。去分母相当于把门槛拆掉，于是一些本来进不来的「解」也混了进来。算完得把门槛装回去，把混进来的赶出去。

想明白为什么 分式方程为什么必须验根

验根不是检查算错，是检查「有没有不小心乘了 0」。

  1. 分式的前提写在分母上

    分式有意义要求分母不为 0。这个限制属于原方程，变形之后的整式方程里已经看不到它了。

  2. 解分式方程的第一步做了什么

    两边同乘最简公分母，把分式方程变成整式方程。这是「等式两边同乘一个式子」。

  3. 等价变形有条件

    只有当这个式子不为 0 时，变形才是等价的。若解出的 x 恰好让公分母为 0，相当于两边乘了 0 —— 任何等式乘 0 都成立，于是冒出了一个假解，叫增根。

  4. 所以验根要代回分母

    把解代入原方程的各个分母，只要有一个为 0 就必须舍去。这一步不是可选项。

  5. 化简求值也绕着分母转

    约分的前提是分子分母有公因式，而字母的取值不能让分母为 0。所以题目常常先问「x 取何值时分式有意义」。

所以分式的一切问题都围着「分母不为 0」：取值范围、约分条件、增根，全是它的不同面孔。

要记住的几件事

分式有意义：分母 ≠ 0

只看分母，和分子无关。分式的值为 0 则要求分子为 0 且分母不为 0。

约分不改变取值范围

(x²−9)/(x−3) 约分后是 x+3，但原分式在 x = 3 处仍然没有意义。

解分式方程先去分母

两边同乘最简公分母，把分式方程变成整式方程，这是通用思路。

增根必须舍去

去分母可能引入原方程不允许的解。解完一定代回原方程的分母检验，使分母为 0 的要舍去。

! 最容易错的地方

解完分式方程不检验，直接写答案。第 3 题解出 x = 3 看着挺正常，可它让分母 x − 3 变成 0，是增根，原方程其实无解。这一步不是走形式，是真能改变答案。

中考怎么考 分式化简求值是计算题固定项，分式方程必考检验

  • 选择题／填空（3 分）：分式有意义的条件、分式值为 0 的条件。
  • 化简求值（6 分）：先化简再代值，代的值还不能让分母为 0——题目常故意给几个候选值让你挑。
  • 解分式方程（6 分）：去分母、解整式方程、检验，三步缺一不可。
  • 易错点：不检验导致增根当答案；代入的值使分母为 0。
典型设问　先化简再求值：(1 − 1/(x+1)) ÷ (x/(x²−1))，其中 x 从 −1、0、1、2 中选一个合适的值代入。
怎么想　化简后得 x + 1（过程中用到 x²−1 = (x+1)(x−1)）。选值时要让原式中所有分母都不为 0：x ≠ −1、x ≠ 1、x ≠ 0，所以只能选 x = 2，结果为 3。「选一个合适的值」就是在考你有没有注意分母的限制。
