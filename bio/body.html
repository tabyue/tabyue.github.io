最后被拆成什么

  • 淀粉 → 先变成麦芽糖 → 最后变成葡萄糖
  • 蛋白质 → 最后变成氨基酸
  • 脂肪 → 先被胆汁乳化成小颗粒 → 最后变成甘油和脂肪酸

这些小分子主要在小肠被吸收进血液。水、无机盐和维生素不用消化，可以直接被吸收。

想明白为什么 血液为什么要走两条路，不能合成一条

因为一条管「给全身送氧」，另一条管「去肺里取氧」，功能不同，不能合并。

  1. 小肠为什么是吸收主场

    长 5—6 米，内壁有皱襞和大量小肠绒毛，使表面积极大；绒毛壁只有一层细胞，内有丰富的毛细血管和淋巴管。面积大、壁薄、血管多，所以既能消化又能吸收。

  2. 大分子必须先拆开

    淀粉分解成葡萄糖，蛋白质分解成氨基酸，脂肪分解成甘油和脂肪酸，才小到能穿过小肠壁进入血液。没拆开的分子吸收不了。

  3. 体循环：把氧送出去

    左心室 → 主动脉 → 全身各级动脉 → 组织处毛细血管 → 各级静脉 → 上下腔静脉 → 右心房。在组织毛细血管处交出氧、带走二氧化碳，动脉血变成静脉血。

  4. 肺循环：把氧取回来

    右心室 → 肺动脉 → 肺部毛细血管 → 肺静脉 → 左心房。在肺部毛细血管处放出二氧化碳、吸进氧，静脉血变成动脉血。

  5. 两条路在心脏接成一个「8」

    两条通路各有起点和终点，在心脏处衔接成一个连续的循环。所以判断某处血管里是动脉血还是静脉血，要看它刚经过哪种毛细血管网，不能看血管的名字 —— 肺动脉里流的就是静脉血。

所以记住两条路线的起止和「在毛细血管处换气」这一点，血型、输血、血管判断题就都有了依据。

要记住的几件事

两条循环路线

体循环：左心室 → 主动脉 → 全身各级动脉 → 全身毛细血管 → 各级静脉 → 上、下腔静脉 → 右心房。血液把氧气送给细胞，由动脉血变成静脉血。
肺循环：右心室 → 肺动脉 → 肺部毛细血管 → 肺静脉 → 左心房。血液在肺里拿到氧气，由静脉血变成动脉血。

心脏和血管

心脏有四个腔，左心室壁最厚，因为它要把血液泵到全身。心房和心室之间、心室和动脉之间有瓣膜，保证血液只能向一个方向流。动脉把血从心脏运走，静脉把血运回心脏，毛细血管最细，红细胞只能单行通过。

小肠为什么最会吸收

小肠很长，内壁有许多皱襞和小肠绒毛，大大增加了吸收面积；绒毛壁和里面的毛细血管壁都只有一层细胞，营养物质很容易进入血液。

血液的成分

血液由血浆和血细胞组成。红细胞运输氧气，白细胞吞噬病菌，血小板帮助止血和凝血。

! “动脉血”不是“动脉里的血”

动脉血、静脉血看的是含氧多少，不是看在哪种血管里。肺动脉里流的是静脉血，肺静脉里流的是动脉血。另外，胆汁里没有消化酶，它只是把脂肪乳化成小颗粒。

打个比方 血液循环像深圳的快递网

心脏是转运中心，动脉是送货的主干道，毛细血管是进小区的最后一百米，静脉是回程的路。肺是“进货仓”，在这里装上氧气；小肠是“食品仓”，在这里装上营养；肾是“回收站”，把废物筛出去。

会考怎么考 血液循环是难点，血管与血液类型最易混

  • 识图：心脏四腔与相连血管，体循环与肺循环的路径。
  • 辨析：动脉血与静脉血按含氧量区分，不能按血管名称判断。
  • 血液成分：三种血细胞的功能，血常规化验单的简单判读。
  • 常见失分：认为动脉里一定流动脉血（肺动脉是反例）。
典型设问　为什么说肺动脉里流的是静脉血？
怎么想　血管的名称按血流方向命名（离开心脏的叫动脉），而血液的名称按含氧量区分。肺动脉从右心室把含氧少、二氧化碳多的血液送往肺部进行气体交换，所以它是动脉血管但里面流的是静脉血。同理肺静脉里流的是动脉血。
