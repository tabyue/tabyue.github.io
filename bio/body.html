最后被拆成什么

  • 淀粉 → 先变成麦芽糖 → 最后变成葡萄糖
  • 蛋白质 → 最后变成氨基酸
  • 脂肪 → 先被胆汁乳化成小颗粒 → 最后变成甘油和脂肪酸

这些小分子主要在小肠被吸收进血液。水、无机盐和维生素不用消化，可以直接被吸收。

要记住的几件事

两条循环路线

体循环：左心室 → 主动脉 → 全身各级动脉 → 全身毛细血管 → 各级静脉 → 上、下腔静脉 → 右心房。血液把氧气送给细胞，由动脉血变成静脉血。
肺循环：右心室 → 肺动脉 → 肺部毛细血管 → 肺静脉 → 左心房。血液在肺里拿到氧气，由静脉血变成动脉血。

心脏和血管

心脏有四个腔，左心室壁最厚，因为它要把血液泵到全身。心房和心室之间、心室和动脉之间有瓣膜，保证血液只能向一个方向流。动脉把血从心脏运走，静脉把血运回心脏，毛细血管最细，红细胞只能单行通过。

小肠为什么最会吸收

小肠很长，内壁有许多皱襞和小肠绒毛，大大增加了吸收面积；绒毛壁和里面的毛细血管壁都只有一层细胞，营养物质很容易进入血液。

血液的成分

血液由血浆和血细胞组成。红细胞运输氧气，白细胞吞噬病菌，血小板帮助止血和凝血。

! “动脉血”不是“动脉里的血”

动脉血、静脉血看的是含氧多少，不是看在哪种血管里。肺动脉里流的是静脉血，肺静脉里流的是动脉血。另外，胆汁里没有消化酶，它只是把脂肪乳化成小颗粒。

打个比方 血液循环像深圳的快递网

心脏是转运中心，动脉是送货的主干道，毛细血管是进小区的最后一百米，静脉是回程的路。肺是“进货仓”，在这里装上氧气；小肠是“食品仓”，在这里装上营养；肾是“回收站”，把废物筛出去。
