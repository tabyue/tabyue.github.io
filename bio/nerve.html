神经冲动的路线

一个反射弧有五个部分，少了哪一个，反射都完成不了。

顺序部分在这个例子里
①感受器手指皮肤里的神经末梢
②传入神经有神经节的那一条
③神经中枢脊髓灰质里
④传出神经通向肌肉的那一条
⑤效应器手臂上的肌肉

痛觉不是在手指产生的，而是神经冲动沿脊髓白质上行，到大脑皮层才产生痛觉。所以总是先缩手，后觉得痛。

看近处时，睫状体收缩，晶状体变凸（曲度变大），折光本领变强；看远处时，睫状体放松，晶状体变扁。长时间近距离看手机、看书，睫状体一直紧张，久了晶状体凸起来回不去，或者眼球前后变长，就成了近视。

想明白为什么 手碰到烫东西，为什么先缩回来后觉得疼

因为两件事走的是两条长度不同的路。

  1. 反射要走一条完整的弧

    反射弧由五部分组成：感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器。任何一环断了，反射就不会发生。

  2. 缩手的中枢在脊髓

    信号传到脊髓就能直接发出指令让手臂肌肉收缩，不必上传到大脑。路径短，所以动作快。

  3. 痛觉必须上传到大脑

    疼的感觉要等信号沿脊髓继续上行到大脑皮层的躯体感觉中枢才产生。路径更长，所以感觉比动作晚一步。

  4. 由此分出两类反射

    简单反射（缩手、膝跳、眨眼）中枢在脊髓，生来就有；复杂反射（听到铃声走进教室、望梅生津）需要大脑皮层参与，是在生活中形成的。

  5. 近视为什么要戴凹透镜

    看近物时晶状体变凸，长期过度用眼会使它凸度过大或眼球前后径变长，远处物体的像落在视网膜前方，所以看不清。凹透镜能让光线先散开一点，把像推回视网膜上。

所以凡是「来不及想」的动作，中枢都在脊髓；凡是有感觉、有意识的，一定经过大脑皮层。

要记住的几件事

反射和反射弧

人体通过神经系统对刺激作出的有规律的反应叫反射，完成反射的结构叫反射弧：感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器。神经系统结构和功能的基本单位是神经元。

两种反射

生来就有的叫非条件反射（简单反射），如缩手反射、膝跳反射、眨眼，神经中枢在脊髓或脑干；后天学会的叫条件反射（复杂反射），如望梅止渴、听到上课铃走进教室，需要大脑皮层参与。

视觉在哪里形成

光线 → 角膜 → 瞳孔 → 晶状体 → 玻璃体 → 在视网膜上形成物像 → 视神经 → 大脑皮层的视觉中枢形成视觉。

激素调节

激素量少作用大。幼年生长激素太少会得侏儒症；甲状腺激素太多会甲亢，缺碘会得地方性甲状腺肿（大脖子病）；胰岛素分泌不足会得糖尿病。

! 物像 ≠ 视觉

视网膜上只是形成物像，真正“看见”（形成视觉）是在大脑皮层。同样，痛觉也在大脑皮层产生。近视眼要戴凹透镜，戴凸透镜会更模糊。

会考怎么考 反射弧与眼的结构，推理题较多

  • 识图：反射弧五个环节、眼球与耳的结构名称及功能。
  • 推理题：反射弧某一环节受损后，感觉和运动分别是否存在。
  • 辨析：条件反射与非条件反射（是否需要大脑皮层参与、是否后天形成）。
  • 近视：成因（像落在视网膜前方）与矫正（凹透镜），结合用眼卫生。
典型设问　某人脊髓受损后，针刺下肢没有感觉也不能缩腿，若只是传出神经受损呢？
怎么想　脊髓受损若传入通路中断，刺激无法上传，既无感觉也不能运动。若只有传出神经受损，刺激仍可经传入神经传到中枢并上传大脑，所以有感觉，但指令无法到达效应器，不能运动。判断依据是看断点在传入侧还是传出侧。
